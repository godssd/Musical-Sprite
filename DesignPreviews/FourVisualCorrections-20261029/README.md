## 实现依据

- HUD：HP、分数、叶片、短笔触与火苗的位置统一从血条端点和字高计算。固定六位容量，血条长度不随分数改变；红蓝文字保持可读、不镜像。调整整体占比和主次，比分字体 64→76，HP 36→38；两侧逻辑设计宽度720→760，曲带505→565。
- 配色：素材提供 alpha 造型与纸纹，血条/头像框/月牙/笔触统一使用队伍颜色；HP 和分数采用统一染色流程，分数与 HP 标签奶白。修复血条着色分支绕开材质 Tint 的问题。没有重画基础 PNG。
- 过热火苗：底部锚定实际分数字形上方约三分之一处；原先固定 HUD y 值使火苗被数字挡住。保留小火苗、两色、少量火星和退出衰减。
- Combo：取消横纵网格切割，采用中心稀疏、外围密集的确定性 Voronoi 分块；共享毛边切口、窄纸纤维边、拉扯后分离；真正的 shader 去色防止奶白字库乘灰后发褐。0.30秒结束；零连击不撕碎，新命中取消旧碎片。没有改动 Combo 的定位函数、位置或字体图片。
- 四轨：永久辅助线不再复用命中光的快速衰减曲线；完整延伸至分界前，命中边光与场内柔光覆盖范围接近半场全长。保持四轨五条共用边线、红蓝镜像、直线边缘和成功/按下独立状态。
- 分数增位：保留现有数字的不透明度，仅新数字补入，避免整行因为位数改变闪没。
