# 血条待兑现区间规则（2026-11-02）

- 实际 HP 和数字立即更新，不修改战斗数值；只改变血条显示与等待逻辑。
- 末次有效扣血后，包含 1.2 秒的时间内，黄色显示边界完全不移动。白闪时间包含在这 1.2 秒内，不额外相加。
- 再次扣血：扩大黄色区间，立即停止尚在进行的黄条下降，重新完整等待 1.2 秒；之后继续使用原先快后慢的阻尼收束。
- HP 归零：立即清除等待，下一次显示更新即开始下降；刻度真正抵达零后再爆开并结算。若显示刻度已为零，则没有需要等待的下降过程。
- 继续回血：目标血量上移，绿色区间直接累积，不重新启动既有回血的等待，也不重置已经进行中的移动速度。
- 回血期间受到伤害：先降低绿色区间的末端；只要新血量仍不低于实体边界，实体血条不动、不生成黄色。剩余绿条继续兑现。
- 恰好耗尽绿色：绿条结束，既不生成虚假的黄色，也不产生额外等待。
- 伤害超过绿色：仅将超出绿色的部分变为黄色，按末次扣血后的 1.2 秒等待规则执行。
- 既有白闪、黄绿光效、数字阻尼、静态布局与入场不变；损血等待期间收起移动光，不把恰好 1.2 秒的边界误判成正在移动。
