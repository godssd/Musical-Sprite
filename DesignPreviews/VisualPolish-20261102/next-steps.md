本文按用户最新会话整理。早期 V5 的造型、即时刻度、损血时长、技能箭头和胜利动效等冲突要求不再采用。

## 本轮已改

1. 黄绿条：移除沿上下边界连续生成高光的路径。以填充区域的柔化覆盖估计外光，并用原始素材 alpha 排除实体内部；色块保持原色，不再叠加白色边线。刻度独立保留细白核心、同色近光及远光。
2. 暂停/移动/完成：保持上一轮确认的 1.2 秒刷新暂停、绿条优先抵扣、归零解除等待及阻尼收尾规则。
3. Combo：原字形上增加下部暗色渐变，强度 24%；撕碎碎片继承原始字形的渐变位置，灰化与渐隐时不会突然丢失明暗。
4. 此轮不重做常态血条、轨道、过热布景、入场或整体排版。现有旧 UI 继续保留隐藏。

## 接下来重点：血条细节收敛

| 顺序 | 调优内容 | 观察标准 |
| --- | --- | --- |
| 1 | 实体、外光、刻度的亮度主次 | 黄绿实体没有亮框；移动刻度最亮，柔光不冲白色块、不抢分数 |
| 2 | 1.2秒暂停与恢复 | 等待时边界完全固定；重复受伤立即停住；恢复时有明确起势，后半程柔顺收住 |
| 3 | 小变化与连续变化 | 小额回血/扣血仍看得出；高频事件不重复爆亮、不卡顿；绿色被抵扣时不闪出黄色 |
| 4 | 满血、残血、零点 | 满血刻度不外露；残血只暗闪；归零立即开始下降，真正到零才爆开、结算 |
| 5 | 数字与位置 | 1–6位分数、1–3位生命值、红蓝镜像下不挤压；缩放以整组中心为基准，头像与血条稳定 |
| 6 | 入场与收尾 | 加载头贴形，完成同拍变色和前向碎光；重开没有旧粒子或虚血残留 |
| 7 | 实际显示尺寸 | 1920×1080与缩小Game视图、移动端比例分别看细边和软光，不能只看放大截图 |

调优方法：每轮只改变一个视觉维度，固定同一事件、血量比例和画面时间作前后对照。分别观察无背景预览和实际复杂背景。原速短动图评价节奏，静态帧评价轮廓、颜色与排布。通过逻辑回归不等于视觉定稿。

Combo、音轨与现有过热后续只做低幅度统一：渐变明度、灰化连续性、光的饱和度和尾部衰减，不改已确认造型、位置、轨数和玩法。

## 大计划后续

1. **先完成血条这轮收敛并由用户实机审查。** 当前重点，不分散到其他新模块。
2. **制作并接入评价 UI。** 统一手绘字形和轻量装饰，覆盖实际存在的 PERFECT / GOOD / CLEAR / PASS / YES / MISS 等映射；BREAK 与 MISS 功能一致。核对真实事件，避免一次评分重复播或合法连续判定被吞。现有旧评价保留，先小样再接入。
3. **制作技能输入的专属图标与状态。** 从上到下为勇气、守护、坚韧。图标表达语义，兼容玩家改键与移动端点击，不将方向箭头当作最终图标。有效输入播按下反馈，对应角色继续使用原技能动画；无人符合时清空输入并锁住重置表现期；完整指令成功时整组反馈，表现期禁止再次触发。
4. **自然背景、场内光影与轻度卡通统一。** 原地面、场景件与角色保留。先做背景与局部冷暖光的小样，控制明暗层次和信息密度；不默认叠加大面积雾。能量槽与溶解保留。现有过热布景只做必要的融合微调。
5. **整局合成与适配。** 检查成功、失败、断连、断过热、连续伤害治疗、技能释放和重开；再核对不同分辨率、移动端触屏热区、材质与渲染开销。UI 全部敲定后才讨论清理旧资源，不提前删除。

这里列的是后续顺序，不代表已经开始或完成。用户当前收敛意见优先于旧文档。
