# UI 动效逻辑与一体判定带

2026-10-23 · 待评估设计，未接入 Unity。

## 设计与逻辑的边界

游戏先计算结果，UI 读取结果再播放动画。动画不反写 HP、分数、Combo、技能能量或判定。初始化、场景恢复、无变化的数值同步直接显示，不误播受伤或加分。

本方案延续已选手绘 UI 母版。新造型图为 `unified-judgement-ribbon-v1.png`，显示同一条判定带的常态、按下、命中，不是三个备选外观。

## 1. HP

- 当前 HP 小于上一真实 HP：播放扣血组。HP 数字立即更新，主色带按原配置 0.8 秒收缩；黄色损失残影停 0.25 秒后用 0.7 秒收回；液面晃动保持 0.55 秒。
- 保留整条受击闪白，但最亮部分集中在前 60–90 ms，余下衰减为柔光，整个包络仍以 0.5 秒为起点。回弹总长保留 0.3 秒；大伤幅度建议从原上限 1.2 比较到 1.10–1.14，作为表现参数，不改变伤害。
- 叶片延后约 40 ms 跟随主体回弹，根部固定。
- HP 增加（2026-10-23 更新）：新增血量区间先以绿色虚血显示，主色填充从当前显示值追上，逐步覆盖绿色，追上后绿色消失；数字立即显示真实 HP。扣血虚血仍为黄色。详细规则与最新四轨整局图见 `battle-final-four-lanes-healing-v4.md`。
- 连续扣血：当前画面接续到最新目标，不回跳、不堆叠放大；残影合并。回血打断扣血时按最新 HP 重定向填充，并取消过时的损失段，避免把回血画成继续损失。
- HP 不变：不播。HP 为零：主条收尽，由游戏结算控制后续状态，不由 UI 自行判断胜负。

## 2. 分数

- 仅当本方真实分数变化：变化数位短距离上提更换并落定，约 120–160 ms；其他数位和另一方保持稳定。
- 普通判定得分：可以附带叶尖一次轻摆。保底补分或静默校正：只更新分数，没有命中庆祝。
- 一次命中同时引发加分与 Combo：两者并行开始，但分数动作比 Combo 弱。不能用分数更新推导 Combo +1。
- 连续加分：追最新目标，替换上一过渡，不排队。无变化的 SetScore 不重启动画。
- 位数增加时预留宽度、保持对齐，不能把整条 HP 曲线挤走。低清晰度时可以用数字立即替换加局部高光的简化版。

## 3. Combo

- 真实连击数增加：数字轻压到约 0.97，回弹到约 1.06–1.08，再归位，总计约 200–220 ms；两侧短弧展开，花草仅叶梢跟随。
- 真实连击数清零：数字、短弧在 140–200 ms 内回收淡出；底座随后淡出，延续零连击不显示数字。下一次有效计数再出现。
- 被技能削减：更新为降低后的数值，短弧向内收、短暂变暖后恢复；不能播放增加连击的回弹。
- 位置仍跟随原本的判定线到中央分界之间的锚点，子节点负责动效。
- 每十连击强化叶片仅为可选表现，不作为默认必加项；不引入新玩法奖励。
- 当前代码对 BREAK 的可见 Combo 与 Fever 处理不同。UI 接入必须消费最终确认的 Combo / Fever 状态，不能为了动画一致擅自把 BREAK 改成清零或加一。

## 4. 评价文字

- 在真正产生判定等级后出现，按键本身不生成成功评价。
- PERFECT：奶油字与本方渐细弧线，轻弹、短停、柔和淡出，总计约 0.54 秒。GOOD 同造型弱一档、无散点，约 0.45 秒。
- CLEAR / PASS：沿用实际判定文本，分别用舒展短弧 / 小一档轻反馈，不包装成 PERFECT。
- 若继续显示现有 MISS / BREAK：灰紫文字、短弧回收，没有命中亮点；文字映射沿用游戏规则。该项不决定 Combo 是否清零。
- 长按起手和完成评价只在逻辑产生相应事件时播放，持续按住不每帧重播。持续得分事件不应被 UI 擅自扩展成反复的大号 PERFECT。
- 同轨密集评价复用一个显示位置，重定向或替换内容，最多短时两层交接；不同音轨可以独立显示。
- 浮起距离为字高约 10–15%，不长距离穿过场内。

## 5. 技能箭头

1. 物理按下：当前箭头和开口环轻压至 0.95，再于 120–160 ms 回位。此时只表达输入被收到。
2. `Accepted`：当前输入是至少一个可用技能序列的合法前缀。点亮当前环的一小段，保留角色已有 SkillSelect 呼应。
3. `Triggered`：逻辑确认调用技能释放。连接曲线流光、环尾舒展，约 350–450 ms。此反馈表示开始释放，不代表技能已命中目标或整段技能执行结束。
4. `Rejected`：没有合法候选。三个环短暂偏暖并向内收，清空输入痕迹，不播放释放流光；通过形变区分红方错误，避免只依赖颜色。
5. 超时：超过配置 `inputInterval`，输入痕迹约 160 ms 消退，缓冲清理由同一逻辑状态同步。
6. 后续输入或候选变化：只保留当前有效缓冲的痕迹。若技能开始后按钮仍可服务其他可用技能，不因为单个技能动画而禁用整组按钮。

箭头的视觉缩放不改变点击范围。三个按钮共用于多个角色、不同长度的序列，不固定画三格进度，不建立公共冷却条。能量与冷却仍由原能量槽表达。

## 6. 一体判定带

### 造型

一条连续的红 / 蓝手绘带，四段对应四条音轨。通过浅色笔触和收窄处区分段落，外侧轻微厚薄变化，内侧真实判定边界保持稳定。无额外灯壳或另一根底杆。

图为放大造型展示。落地宽度从约 12–18 个 1080p 屏幕像素试起，再结合实际投影调节；数字 1–4、文字标签和放大框仅用于设计说明，不进入游戏。所有色带和光晕不改变碰撞或音符判定坐标。

### 状态顺序

| 事件 | 同一判定带如何变化 | 结束后 |
|---|---|---|
| 没有输入 | 红 / 蓝哑光主体，细奶油笔触，低对比音轨引导 | 保持常态 |
| 对应音轨按下 / 持续按住 | 整段柔白光，加向场内的低透明柔光渐变 | 松开后约 0.10–0.15 秒回常态 |
| 收到有效成功判定 | 整段提高亮度，白芯偏本方色，同时该轨上下两条边光向场内逐渐变淡、变窄并轻微转紫 | 强光衰减约 0.28–0.35 秒；若仍按住回到柔白按住态，否则常态 |
| 空按 / MISS / BREAK | 不触发成功彩光和两侧边光；输入态只按实际按键状态处理 | 正常松开衰减，不闪整条失败光 |
| 连续成功判定 | 同一光强包络重触发，限制峰值 | 不让多次 additive 无限叠加 |
| 睡眠 / 禁用 / 结算 | 清掉按住与命中残留，表现随对应可用状态收起 | 恢复时重新读取状态 |

长按成功起手时可以出现一次彩色命中峰值，之后仍按住则维持柔白输入态；完成后若产生 CLEAR 再播放成功峰值。技能箭头输入与四音轨判定输入是不同入口，不互相触发对方的灯光。

## 7. 并发与优先级

- 同一个判定带：命中峰值 > 按住光 > 常态。禁用时清空全部反馈。
- 同一个数字：新真实数值覆盖旧动画目标，动画不能积压。
- 同一 Combo：减少 / 清零打断正在播放的增加回弹。
- 不同 UI 可以并行动作，但血条受伤和音轨命中承担最强反馈；分数叶片等装饰保持较弱。
- 能量槽原样保留；本轮没有新增节拍常态循环、全屏闪白或新的冷却规则。
