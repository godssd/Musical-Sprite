## 分数与动画

- 实际两侧 ScoreDisplay 改用同一套 0–9 图片字库，以白色顶点色保留原图奶油色；旧绿色 / 黄色 Text 停止渲染。
- 初始化显示真实数值，不在 Start 强行清成 0。
- 同值不播放动画，另一侧同步不会跟着跳。有效增长仅让数字子节点做小幅反馈，根定位不缩放；复位 / 减少不播增长反馈。
- 本次接入整体小幅增长反馈；完整“变化位独立入位”的分数动效仍属后续批次，不宣称已完成。
- HP 原受伤与绿色治疗逻辑不变；填充、黄色虚血、绿色回血与闪光沿同一主体位置显示。固定尾饰不参与填充裁切。
