# 曲线血槽 V6：素材审查稿

本轮仅调整素材与组合稿；游戏仍绑定 ConnectedV5，不修改运行代码或配置。

## 修改

- 血槽由等厚胶囊改为浅弧笔触：靠外侧饱满，向分数方向收细，末端圆润。
- 连体月牙与底线沿用 V5 母版，未重新绘制另一种风格；通过血槽左端内移、底线下移形成独立空间。
- 分数、末端叶片与三笔触在组合稿中随底线调整垂直关系，数字字库和字高不变。
- 主体、月牙内壁、底线之间留出连续可见的背景，满血不相切。
- 红蓝使用同一图层着色与镜像；血量变化只裁切独立血槽，月牙底线保持完整。
