## 如何查看

实际游戏中直接触发断连；不需要执行场景安装器。

隔离小样入口：**Tools → Musical-Sprite → V11 → 04 Combo Growth And Tear Review**。

1. 点击“载入 / 重建小样”。默认读取当前战斗绑定的 Combo 字体；未找到时使用 Unity 内置字体。字体可拖入替换，仅作用于小样。
2. 选择 1、8、55、100、12345，或填写自己的连击数，点击“MISS / BREAK 断连”。
3. 用“撕碎定格（秒）”查看中间状态；拖动时重新建立同一个数字快照并前进到选定时间，不使用另一套模拟绘制。
4. “断连后 0.1 秒命中”显示新连击对旧碎片的覆盖；“零连击时再次失败”应没有数字和碎片。
5. “削减 3”检查非零削减的收束；扣到零则走同款撕碎。

## 可调系数

游戏系数位于实际左右 ComboDisplay 组件的 **V11 连击反馈**，两侧默认一致；编辑器小样的系数不会写入游戏。

| 字段 | 初始值 | 含义 |
|---|---|---|
| Growth Peak | 1.07 | 正常增长的最大缩放，只作用数字子节点 |
| Growth Duration | .16 s | 增长或非零削减的整个缩放时长 |
| Tear Duration | .30 s | 从旧数快照到碎片完全消失的总时长；各阶段按比例缩放 |
| Tear Spread | .16 | 相对数字实际高度的分离量；0 不分离，但仍灰化淡出 |

旧 Pop Scale / Pop Duration 保留序列化兼容，已隐藏，不再驱动 V11 动画。游戏颜色暂沿用已有 Combo Color。

## 技术与素材边界

- 单个可复用 MaskableGraphic 承载整组碎片，不创建碎片 GameObject，不截屏，不要求字库 Read/Write，不每帧随机改变裂口。
- 捕获实际字形，不包含旧 Text 的 Outline / Shadow 扩展网格。正式新 UI 不应依靠黑色描边恢复旧风格。
- uGUI 默认材质保留 stencil / RectMask2D 支持；动态字体 atlas 重建时刷新碎片 UV，防止其他 UI 新字进入字库后出现错误字形。
- 动画使用游戏 deltaTime；暂停冻结。小样由独立编辑器时间推进，退出窗口销毁预览场景和 RenderTexture。
- Combo 定位改用真实父 RectTransform 和 Canvas camera 转换，保留原世界锚点计算，不再假定所有 Canvas 均居中。
- 当前仍使用原游戏字体，**不是正式手绘字形、COMBO 标题、小侧弧和两枚叶片的完整美术替换**。本批先交付可适配真实数字的撕碎路径，后续正式字形接入后需复审碎片尺度。
- Fever 数据规则接入本批；全新双层过热布景和断过热退场美术尚未实施，继续走后续布景批次，不把旧场景的退出当作新效果完成。
