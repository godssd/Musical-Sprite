## 对 V4 的修正，正式制作必须执行

- 真实血量与延迟区间分离：真实 HP 当帧跳变，非满血时的小刻度始终标记真实 HP，当帧到新位置；变化时提亮/增大但仍裁切在槽内。延迟边界只控制黄绿实色追赶，不能把真实刻度留在旧值。
- 损血瞬间队伍色到新目标 p，损失区间 [p,old] 闪同队白色，随后转暗黄并停留。延迟边界 d 从 old 移到 p，黄区 [p,d] 实色缩短，d 之后为空槽。真实刻度一直在 p。
- 回血新目标 p 当帧确定，刻度直接在 p，新增区间 [old,p] 闪同队白色并转绿；实血追赶边界 d 从 old 到 p，绿色 [d,p] 缩短，旧边界不能额外画第二根白刻度。
- 刻度不满血常驻，安静时小且完全收在血槽内。满血不要求常驻刻度；归零等事件与真实刻度/延迟尾段的最终时序需统一到最新规则，不能沿用 V4 把真实刻度作为延迟值的实现假设。归零爆开仍在零点位置，不因数字更新提前爆开，可在延迟损失尾段归零时触发。
- 血槽内侧末端属于同一填充遮罩，不能残留孤立亮色钩。外侧身份月牙、头像框是独立装饰，正常保留。所有特效不得改血槽轮廓或固定六位长度。
- 头像仅替换内容；战斗中不变形不染色。入场使用同一整体加载遮罩让头像区显示白色轮廓，完成后露出用户图片，不要求头像自身有定制动画。

## 预览限制与核查

生成图不作为基础 UI 新素材，不逐帧替换使用；正式制作必须重用已定基础图和 alpha 遮罩，否则无法保证像素造型不漂移。示意中的弧度、填充比例、字距不能覆盖既定基础样式。

仍有细节误差：红方回血闪动格的旧边界略亮，必须只保留真实目标处一根刻度；红方延迟格末端仍有微小红色残点，正式统一遮罩要清除。蓝方图的“+245”小标题应为目标 245，不是加了 245。入场蓝方第4格标题有生成文字错字，含义是“转回默认色”。这些不属于方案要求。

循环关键帧只供比较形状，不证明无缝循环。断过热一行是一次性退出，不应按图中复用的“接回A”标签循环。超级过热尺寸是本轮视觉候选，需用户审查与场景缩略尺寸核对，不能直接作为固定正式参数。
