## 最新规则（覆盖 V3 对应部分）

基础造型锁定，血槽轮廓、厚薄、固定六位长度和排布不得被特效改变。刻度必须以原路径法线方向的窄截面实现并裁切在血槽内，不使用外部直光棒。

- 图1：损失/新增区间先闪白一次，再变暗黄色/绿色停留，随后刻度延迟移动至目标，黄/绿区间随追赶消失。常态刻度保留清晰但降亮。濒危血条明显间隔闪亮，头像和分数不参与闪动。
- 图2：普通过热降低到轻量火花，超级过热明显增强高度/密度/亮度，均在分数背后持续循环；断过热从当前循环姿态接续扑灭，不强制回初始帧。
- 图3：归零延迟扣血期间不爆炸，刻度到零点才从零点爆开熄灭。入场初始没有 UI，以偏白发亮的暖色充能刷新显示整套 UI，不额外渐显；完成转回默认色瞬间出碎光点并触发短促提示音，不出现声音文字；头像内容不定制变形。没有胜利特效。

## 制作与图片审查边界

图中阶段说明为时序依据，但填充位置/数值比例并非精确测量。图1损血移动格中黄色残留边界仍不够准确：正式组件应是实血0～新目标、黄色新目标～当前延迟刻度、当前刻度之后空槽，刻度从旧值连续移向目标；不能把整段黄条等比例淡掉。回血应是实血0～当前刻度、绿色当前刻度～治疗目标。

部分空槽尾钩仍有亮色，归零图生成了细轮廓描线，入场扫描中未加载区也有少量残留，这些都是生成示意误差，不应作为新增基础造型或提前显示规则。正式实现必须直接复用同一原图与同一轮廓遮罩，不能逐格替换生成图；这样才能保证基础 UI 的像素形状不漂移。归零爆点绑定真实路径0坐标，避免误伤头像；入场碎光绑定内侧终点坐标。

循环图首尾为姿态概念，尚不是可直接循环的帧序列；需要拆层或程序粒子实现后验证无跳变。此轮未执行 Unity 或逐帧动画验证。
