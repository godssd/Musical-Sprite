# 2026-11-01 迭代 V6：原稿母版、独立刻度与阻尼节奏

## 本轮实际改动

1. **素材与布局**：从 `DesignPreviews/TeamHUD-MotionV6-20261028/locked-base-reference.png` 按源像素坐标拆出红蓝曲带/月牙、头像框、外侧叶片、端部叶片和分数前缀装饰。没有重新生成近似叶片。采用色彩分离和连通区域清理取得透明遮罩；母版缺乏原始分层，抗锯齿边缘属于重建结果，不宣称逐像素完全等同。月牙和曲带使用同一母版贴图，不再独立拉伸拼接。
2. **排版**：统一原稿坐标关系，分数基线固定；前缀装饰在数字位数变化时移动并保持自身宽高比；血槽长度不随分数变化。保留现有0–9字形，校正奶白色，保留六位数显示上限和红蓝镜像增长方向。
3. **阻尼血量追赶**：实际血量数字仍即时变化，变化区白闪、实色黄/绿停留后，由解析临界阻尼运动驱动虚血边界和刻度。连续同向事件保留当前速度，不重启停留；反向事件在闪光中衔接旧端点，无事件瞬移；黄/绿由事件类型明确驱动，交接白闪覆盖旧虚血与新目标的联合变化范围，避免短暂反色。损血追赶0.46秒、回血0.56秒为本轮初值；末段减速并精确归位。
4. **刻度与光**：新增由原稿遮罩生成的截面表，按实际位置的上下边界适配刻度。常态刻度内收；移动时有独立弧形亮核心与外溢光。去掉第二根条内刻度叠画。黄/绿区保留实色，采用相同结构的内亮层、外光和刻度。
5. **柔光**：预烘焙贴形距离场供UI材质取样，替代反复位移采样造成的叠影。有限距离场末端主动渐隐，避免在UI扩展矩形内留下底色块。原场景Bloom设置不变。
6. **入场**：独立加载刻度不受满血隐藏规则影响；扫到终点后衔接完成光和碎点。减少头像单独等待，保持贴形白光、初始无分数。身份部件的外晕单独收敛，避免轮廓空隙被光完全填满。
7. **完成碎光**：红方朝右、蓝方朝左的前向扇区，不再全圆散射；主要碎光约原尺寸2.2倍，速度/距离分层并阻尼减速，避免全部重叠成一块白光。
8. **Combo**：约0.60秒，快速撕开→阻尼减速并保留纸片→后段淡出；不再同时大幅变暗、灰化和透明。保留逐数字裂口、中心大块/边缘小块、原位置。旧场景序列化0.30秒在手绘模式下迁移为0.60秒，无需保存用户场景。新命中仍立即增长，旧碎片独立结束；同一显示器最多保留一个离场快照，不积累无限对象。
9. **分数小火苗**：基部移至数字上部约8%高度处，避免普通火苗全部被数字遮住；修正宽高和错相呼吸，保留普通/超级的3/5簇及稀疏火星。仍为受约束的矢量轮廓循环，未制作新的序列帧绘画。

本轮没有修改音轨参数、场景后方布景位置、地面、角色造型、中央能量墙或Combo位置。旧UI继续隐藏保留；未保存SampleScene。

- `live/`：1920×1080原生Game View，含Overlay UI；控制时间以得到可重复帧，不是整段自动对战录像。
- `damage.gif` / `heal.gif`：真实渲染组件的阻尼追赶，左右同屏。
- `entry.gif`：白光加载、独立刻度及完成前向碎光。
- `combo.gif` / `combo-new-hit.gif`：0.60秒撕碎，以及撕碎时新连击出现。
- `regression.txt`：帧率一致性、连续事件保速、无超调、有限时间归位、反向变化和归零时机。
- `hud/unity-validation.txt`：真实ScoreManager事件、排版容量、加载刻度和材质检查。
- `live/runtime-validation.txt`：实机捕获及旧UI保留检查。
- `gameplay-regression.txt`：对局扣血、回血、失败等待归零与重开。
