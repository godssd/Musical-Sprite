# V6：锁定原始 UI，恢复光感与小火苗

2026-10-28。设计修订预览，尚未接入 Unity。实际工具为内置 imagegen 的原图局部编辑，提示见 prompts.md。

locked-base-reference.png 是用户此次图1的原始副本，作为基础形状的唯一依据。V3～V5 生成图中重新绘制的血槽不能替代该原图。正式制作必须复用原曲带、头像、叶片、数字样式和布局，特效只作为遮罩/叠加层。

- 01-restored-health-glow.png：顶行原常态对照，中行损血区间发光，下行回血区间发光。恢复亮芯和柔和光晕，红暖白、蓝冷白；不把简约理解为取消光感。此图只比较闪光质感，三行不是连续数值动画，100/50/15 是原图血量行标签。
- 02-small-flames-on-original-ui.png：顶行原常态，中行小火苗，下行加强小火苗；火苗有明确尖端和燃烧姿态，简化两色，适度柔光，不是烂泥色块或大营火。超级过热限制在分数附近，通过数量和强度区别。图中不同 HP 与过热无因果，仅沿用原图三行作比较。
- 03-luminous-entry.png：原曲带趋势的入场光感；从完全空白开始，按实际 UI 轮廓白光加载，外侧只留柔和近距离光晕；未加载区保持空白，不显示暗条或叶片。全白后切回默认色，终点同时出碎光。无分数、无“叮”文字。

仍遵守 V5 的实色黄/绿区间追赶、真实 HP 即时刻度、非满血常驻小刻度、濒危压暗回常态、断过热从当前循环收缩、归零尾段到零点后爆开等规则。本轮只修用户指出的造型、闪光、小火苗大小和入场光感，未重做完整时序板。

## 图片质量边界

图像编辑比重绘更接近原图，但仍不是可证明像素锁定的合成；正式实现不能以编辑后图覆盖原始 UI。需要把特效与原图拆层，直接用原 alpha 约束后验证。入场板因去掉分数及重排阶段有缩放展示，不能作为正式布局坐标。

血量光感对照中蓝方高亮位置有方向误差：蓝方实际从头像外侧向内计量，必须按真实变化区间镜像应用，不能照生成图左端/右端直接编码；原图里空槽内侧的孤立亮尾也需统一血量遮罩处理。刻度尺寸须按真实血槽内部截面裁切。此图的发光强度为候选，不能跳过场景缩略尺寸校验。

所有运行时代码、场景和已有用户调参本轮均未修改，没有执行 Unity 测试。
