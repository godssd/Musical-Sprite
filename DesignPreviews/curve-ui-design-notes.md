# 曲线 UI 方向细化与完整游戏预览

本轮使用内置 image_gen，基于用户选中的曲线节拍方案生成。尚未修改 Unity。

- C1：curve-ui-c1-refined.png。减少装饰和字形噪声，清爽圆环方向键。
- C2：curve-ui-c2-botanical.png。曲线延伸为细枝和叶片，更贴近森林主题。
- C3：curve-ui-c3-cadence.png。短弧、圆点和节拍刻度强化音游反馈，保留曲线字形。
- 完整场景：curve-ui-game-fog-lighting.png。使用用户选中的原方案，加入场地外缘薄雾、场内暖冷光、接触阴影及轻度卡通色彩协调。

角色约束：以原 Unity 截图中的角色身份、姿态、站位为基准，不设计新角色。本轮是生成合成，存在局部线条与图形细节重绘，不能作为替换角色贴图。落地时直接保留原 Unity 角色、音符与其他未要求修改的素材。

判定灯的最终制作依据仍为用户提供的效果图：整段亮起、向场内渐变、非 Miss 命中两侧边缘同步发光。生成预览只表达整体搭配，不替代其细节标准。

三套组件图中的方向键横向排布是为比较造型，实际游戏纵向排列。场景右侧方向按钮为红方技能输入，因此统一红方色；右方判定线仍为蓝色。连击示例周围的植物是背景示意。
