# V11 血槽与装饰线共用走势（仅组合稿）

用户进一步指出血槽仍像独立横向胶囊。本轮调整造型生成关系，而不是继续移动独立图片。

## 方法

- 从 V9 装饰线的上沿主贝塞尔曲线取样，使用与底线同一连续横向伸缩映射。
- 血槽沿其法线向内偏移：血槽下沿与装饰线上沿相隔约 8 设计像素；血槽厚度由 26 平缓收至 24。
- 两端使用与曲线切向相接的圆帽，避免尖角和不相干的水平封口。
- HP 标签与数字一同向下收拢 7 像素，使文字紧随血槽而非远离主体。
- 红蓝由同一局部轮廓镜像；分数继续保持 V10 的较紧凑整体排布。
