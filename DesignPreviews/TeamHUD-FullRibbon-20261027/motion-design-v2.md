## 1. 固定关系

- 分数最醒目，HP 第二，头像与装饰辅助。红方头像在左、分数向右增长；蓝方头像在右、分数向左增长，文字正常阅读。
- 头像仅提供图片替换、等比适配与固定形状裁切。未加载完成时保留占位图，成功后直接替换。头像、外框均不响应受伤、治疗、濒危、过热、胜负，不加更换淡入或专属表情。
- 曲带在 HP 和分数下方的整段均为有效血槽。外侧头像框与身份月牙不属于生命填充。
- 常态不持续摇晃或扫光。原地面、角色、能量槽、四轨判定方案与 Combo 位置不因本提案改变。

## 2. 分数 1～7 位

每位使用相同字高、稳定的占位宽度，按美术字的最大字宽确定 advance。不能随数字数量缩小字号，也不能因 1 比 8 窄而导致整个 HUD 晃动。

头像、HP、靠近 HP 的分数起点固定。红方第一位的左侧锚点固定；蓝方末位的右侧锚点固定。新增位数占据内侧空间，卷钩和末端叶片一起向中央移动。分数反馈的缩放属于视觉子层，不参与布局测量。

| 位数 | 示例 | 需要的数字槽位 |
|---|---|---|
| 1 | 9 | 1 |
| 2 | 58 | 2 |
| 3 | 584 | 3 |
| 4 | 5842 | 4 |
| 5 | 58420 | 5 |
| 6 | 584200 | 6 |
| 7 | 5842000 | 7 |

整段曲带长度 = 固定头像/HP段 + 分数槽位数量 × advance + 尾端安全距离。正式布局从一开始就为两侧各预留七位的最大占用范围；可见尾端仍跟随实际位数。中央始终保留间隙，不以临时压缩分数字号解决碰撞。

1920 宽的初始预算示例（非从概念图精确量取）：外侧边距 32、中央间隙 64，则每侧可用 896；分数起点距本侧外缘 354、advance 62、尾距 36，1～7 位终点分别为 452/514/576/638/700/762/824。七位仍有余量。具体值要按正式字库与头像尺寸检查后暴露为参数。小屏统一按设计分辨率适配，而非仅缩小长分数。

### 2.1 普通加分

真实总分立即写入数据。仅实际变化的字位在约 0.04s 内达到 1.075 倍、上提 2px，约 0.16s 内回稳；其余字位保持稳定。小增量文字约为主分数字高的 1/3，上移约 5px，0.28s 内淡出，不能遮挡 HP 或主分数。

每侧最多一个增量标签，同侧 0.08s 内的加分合并；高频连续输入限制可见峰值频率与最大缩放，数据不合并丢失。标签超过一次连续串的最长可见时间后淡出，不能无限续挂。

### 2.2 跨位数过渡：约 0.20s

| 时间 | 显示 |
|---|---|
| 0 | 提交真实目标；从当前可见长度开始延展曲带，不能先跳到目标宽度 |
| 0～0.05s | 旧的变化字位轻退淡出，未变化的位保持；末端向新目标移动 |
| 0.04～0.12s | 新位在空间足够时短暂淡入并轻提到位，不与叶片/卷钩相穿；允许极短的表现层交接时间 |
| 0.12～0.20s | 卷钩、末端叶片及数字收稳，速度自然减为零，无过冲 |

这是一段旧字退场、新字入场的视觉交接，不显示虚构的中间分数，不延迟业务结算。不能要求新七位数在旧一位数长度内第一帧就完整显示，否则与连续延展相冲突。跨位时变位替换可有至多约 0.12s 的视觉交接，完整目标在交接后可读。

多位跨越直接向最终位数延展，不逐级播放假分数。连续加分从当前长度、速度继续追踪最新目标，禁止每次重新从旧宽度开始；停止输入后约 0.20s 收稳。可用有限时长 Hermite 插值，继承当前速度并限制过冲。单纯把每帧 Lerp 系数设为常量会受帧率影响且难以保证完成时间，不采用。

血槽所有层同时更新路径几何，血量比例不变；增长不触发治疗。应以路径归一化长度映射填充和黄/绿区间，不能分别拉伸边框与填充造成脱节。月牙保持原轮廓，尾钩不横向压扁，中段使用连续曲线衔接，避免切片接缝。

### 2.3 特殊情况

- 同值刷新不播。系统补分只做轻淡换，不加主动得分小字；倍率由计分逻辑提供，不二次相乘。
- 校正降低可用 0.08s 淡换与平滑缩短，不误播加分。重开直接同步 0 与最短布局，不播负分。
- 七位是本轮保证的布局范围，不是计分上限。若业务可达八位以上，应在制作前补最大分数预算；不截断、不伪装成七位、不悄悄限制得分。

## 3. HP 动效

进度 p = clamp(HP/maxHP,0,1)。队伍色、空槽、黄色损失区间、绿色治疗区间共用同一套整段路径遮罩。满血覆盖内侧末端，空血不能残留亮色尾钩。蓝方的消耗方向镜像。

| 情况 | 表现与首轮时序 |
|---|---|
| 损血 | HP 数字更新；血槽有效受损区间暖白闪 0.06～0.09s，HP 数字轻提回落约 0.14s；队伍色回落，黄色损失虚血短留后追平。沿用已调好的 fillDuration/ghostHold/ghostDrainDuration，未配置时参考 0.4/0.1/0.2s |
| 回血 | HP 更新；实际新增区间显示绿色虚血，队伍色追赶，绿色逐渐缩短至消失。沿用当前 healingFillDuration，未配置时参考 0.55s；数字 1.03 倍轻回弹约 0.16s |
| 满血或无实际变化 | 不播虚假的治疗/伤害；真实增量为零不出反馈 |
| 连续变化 | 从当前显示位置接续；旧结束回调不能把新状态覆盖 |
| 回血中受伤 | 当帧撤掉旧绿区间，按最新数据与当前可见位置重建损失尾段 |
| 受伤中回血 | 撤掉旧黄尾段，按新目标重建治疗区间；不混成橙色 |
| 血量上限改变 | 重算比例，单纯分母改变不冒充治疗/损血 |

只在填充边界保留约 1～2px 扰动，整段外轮廓不波动。受伤强度依据实际 HP 差/maxHP 限幅，不能直接使用可能超过剩余 HP 的伤害事件数值。分数、头像完全不参与受伤缩放。

## 4. 濒危、过热、结算与生命周期

| 状态 | 设计 |
|---|---|
| 濒危 | 建议 <=25% 进入、>=30% 退出，HP 数字及当前实血边界做约 1.5s 周期的低强度明暗提示，15～20% 幅度；不变更队伍色，不碰头像与分数 |
| 进入过热 | 分数旁已有小笔触约 0.16～0.22s 点亮一次；同帧加分只调整一次反馈包络，不双重弹跳 |
| 过热持续 | 小笔触保留稍亮状态，分数仍是奶油色；无整条扫光，无血量比例或颜色改变 |
| 超级过热 | 小笔触两次轻亮，约 0.30s，总强度比过热高一档；不增加新头像光圈 |
| 断过热 | 仅在真实非 None→None 时播放，小笔触 0.18～0.24s 收暗；已有损血反馈优先。Fever→Super 直接升级 |
| Combo 断连联动 | MISS/BREAK 同功能。旧 Combo>0 才在原位置播放中心大块、边缘细碎的分层撕碎灰化，约 0.30s；总分不清零，不撕头像或血条 |
| HP 归零 | 血槽及黄/绿瞬态约 0.15～0.20s 收清；HP 为 0，停止濒危与过热。累计分数保留可读，头像完全原样；业务战败即时处理 |
| 胜利 | 已确认结果后胜方分数一次 1.06 倍轻回弹，约 0.22s；不自行重算胜负。平局中性收束 |
| 入场 | 数值已初始化，HUD 内容约 0.20s 渐显、上移 6px 到位；头像静态显示，不单独做入场动画，不滚出虚构分数 |
| 离场 | 分数、HP、曲带约 0.15～0.20s 渐隐，头像随界面关闭直接隐藏，不定制退场 |
| 暂停/恢复 | 表现暂停后接续，不重放加分、入场或过热进入 |
| 重开 | 清掉所有旧瞬态，直接同步真值与最短分数布局，头像保持合法替换内容 |

动效优先级：业务同步最高；HP 归零高于伤害/治疗转向，高于旧黄绿尾段，高于濒危。分数与 HP 可以同时反馈，不互相取消。头像始终没有状态动效。

## 5. 工程入口与素材要求

- ScoreManager.OnScoreChanged 同步目标，OnScoreGained 提供实际增量；部分路径增量事件早于总分刷新，需同帧收集后统一提交表现，不能抓取旧显示值。
- OnHPChanged 与 OnSideDamaged 组合判别真实变化；Heal 到上限可能仍有刷新事件，必须核对真实差值。
- FeverManager.OnStateChanged 驱动顶部笔触，不凭分数推断过热。MISS/BREAK 统一失败，None→None 不虚播断过热。
- 正式素材：0～9 图片字库（统一基线/字高/advance 元数据），HP 标识，头像裁切/占位，静态月牙、连续曲带轮廓、末端卷钩、叶片与小笔触。黄/绿/队伍色通过同形遮罩着色，不各画一套有偏差的血条。
- 同色材质可复用并以顶点色或每实例参数区分，不能修改共享材质而串到另一队。加分标签复用对象，禁用 raycast，避免阻碍触屏技能按钮。
- 纹理边缘需有透明留边、合理图集 padding；缩放后检查奶油数字锐度、血条间隙与曲线接缝。末端叶片与尾钩作为一组跟随长度。
- 不为每种分数生成一张整套 HUD；数字组件与曲带长度由布局组合，才能覆盖全部数值与动态变位。
- 旧 UI 仅隐藏，保留回退；现有判定参数及 Combo 位置不改。
