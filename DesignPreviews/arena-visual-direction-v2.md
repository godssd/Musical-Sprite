# 场景视觉方向 v2（2026-10-22）

本页是效果图和制作方案，不是已进入 Unity 的效果。图像保留了游戏截图的大体布局，但其中新增的灯笼、树木和花草只表示光影层次，不是要添加的场景道具。

## 参考与问题

- 桌面视频 `QQ20261018-92920.mp4` 的采样帧见 `cult-fog-video-analysis/QQ20261018-92920-20261022-142009/frames/`。在 0.689、4.133、8.955 秒等采样帧中，可玩地面保持清楚；场外由明确的草地边缘、深色植被、墙和树分层。视频中的运动伴随镜头移动，单凭这些帧不能断言外围雾本身独立流动。
- `ArenaBoundaryMist.cs` 目前生成朝向相机的平面网格，`BoundaryMist.shader` 让网格上下波动，形状和运动都像悬浮云片；它也没有沿实际场地轮廓遮挡物体。
- `FeverSceneryController.cs` 将源图裁成底部 30%，另生成半透明的 `CreateBackdrop` 网格。四张 fever/super fever PNG 的 SHA256 相同，现阶段没有普通与超级过热各自的画面，更没有循环动画素材。
- 场景件 `ScenePropSprite.shader` 将贴图 RGB 固定乘 0.78，与地面光照方法不同；场内的物件与地面因此难形成统一、细腻的明暗。全局卡通雾 Renderer Feature 目前处于关闭状态。

## 图 A：正常场景、外围空间与场内光影

`arena-normal-lighting-v2.png` 表示：场地轮廓清晰，场内不叠云状雾；场外用数层植被和树干的色值、遮挡与少量视差建立深度，保持比咩咩更明亮的本游戏调性。画面主体是场内的柔和局部亮区、地面色块明暗、角色与道具接触阴影、树叶顶部和背光侧的轻微区别。滤镜只做轻度色彩归一与明暗分阶，保留线稿、贴图笔触和音符清晰度。

实现顺序：
1. 移除现有相机朝向的波动雾网格。在场地边界外用地形轮廓遮罩、两至三层手绘植被/树影与有限视差；极少量空气感只沿地面边缘出现，缓慢平移且不能盖住谱面。
2. 场内选两三处已有发光源做柔和、有限范围的暖/冷光池；将地面、植物和角色的明暗基准统一，补短而软的接触阴影。避免整场泛光和大片光柱。
3. 在世界画面完成后、HUD 渲染前做轻度卡通色彩处理：温冷分区、温和色阶压缩及低强度局部描线。强度可调，避免油画贴图细节和判定 UI 被抹掉。

## 图 B：过热升起的动态布景

`fever-animated-backdrop-v2.png` 左右分别表示普通和超级过热。它们是有完整绘画内容的**背景布景/动态广告牌**：从场地后缘下方升起，底部始终被地面遮住，人物、谱面和场内植物始终在前景。普通过热是较低、较简约的布景；超级过热升得更高、画面元素与内部运动更丰富。图中的白色箭头只是动势标记，不属于最终游戏画面。

实现顺序：
1. 给红/蓝双方分别制作普通与超级过热的独立图稿；每个状态至少拆为前、中、后三层，或制作可循环序列帧，不能继续共用当前四张相同的占位图。
2. 将布景放在真实场地后面，面向主相机，明确排序、深度和地面遮挡；排查粉色平面实际对应的材质/Shader，再绑定专用透明材质。
3. 状态进入时整体升起约 0.5 秒；停留期间内部图层做 4–8 秒无缝循环（少量视差、微弱流光和笔触摆动）；退出时整体降回。循环与升降是两套独立动画，叠层时不发生图像交错。

## 下一步制作门槛

先确认这两张图的空间关系、明暗程度和过热背景的画面方向，再制作可替换的正式分层图稿。之后接 Unity：先修布景贴图/朝向/遮挡，再做场外层次、场内光照和最后的轻滤镜。每个阶段都用 Game 视图的正常、普通过热、超级过热三种截图对照；检查音符、人物、判定线和 HUD 始终清楚。
