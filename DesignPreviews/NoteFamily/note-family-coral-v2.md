## 命中前与命中后

| 音符 | 命中前 | 命中后仍需继续操作 | 整颗音符完成 |
| --- | --- | --- | --- |
| 普通单击、双轨单击 | 透明珊瑚壳、浅色爪印和低亮度上行光。双轨单击跨过两轨。 | 一次有效按下直接完成。 | 命中亮态，压缩回弹，上行光提亮并带出碎屑，随后淡出。双轨单击从实际按下的位置起亮。 |
| 连点 | 透明壳、低亮度上行光和清楚的余数。 | 中间拍 `YES` 扣一次余数。外壳短弹、上行光短亮，然后回落到待命亮度，保留刚更新的余数。 | 末拍 `CLEAR` 给整颗音符的完成反馈，较强的上行光和碎屑集中在这一拍。 |
| 同轨长按、换轨链接、混合宽度长按 | 头、带、尾保持透明。头尾音符带低亮度上行光，连接带自身保留小幅珊瑚色渐变。 | 起手成功提高头节点的上行光。保持按住时，进度填充从头端开始，带内形成已通过和待通过两区。中间节点的 `CLEAR` 给局部反馈。 | 最后一段在尾节点通过判定时完成。尾端短亮并弹出碎屑，连接带按原宽淡出。 |

漏击和断连走各自的退场表现。断连时亮沿随进度退回并关闭，尾端保持普通态直至退场。

### 音符本体的上行光

![音符本体由下往上提亮的方向参考](note-body-upward-glow-reference.png)

平时就有低亮度的暖光贴着果冻壳向上走，轻微点亮侧边和顶部，爪印或余数保持清楚。有效点击时，同一方向的光随果冻回弹更快、更亮地升到顶部，顶部的短亮和壳外光晕更明显。连点中间拍短暂提亮后回落，链接起手只加强命中的头节点，尾端在通过判定时再提亮。

本体光沿外壳向上。链接底带自身的小幅渐变随音符移动，按住后的进度填充则沿连接带推进。

## 连点与链接分镜

![连点命中与链接进度分镜](note-family-coral-motion-v2.png)

| 状态 | 表现 |
| --- | --- |
| 连点中间拍 | 余数随有效点击更新。外壳顺运动方向压窄，弹回时带少量短促亮点。数字以稳定的屏幕中心显示，便于余光确认。 |
| 连点末击 | 亮态与上行碎屑集中在最后一拍，确认这颗音符已完成。 |
| 链接未起手 | 等宽透明底带呈现小幅度的珊瑚色渐变，和音符一起移动。 |
| 链接起手并按住 | 头端亮起，珊瑚色填充从头端开始。未通过的带段与尾端维持透明底色和本身的渐变。 |
| 链接推进 | 带内的填充长度随有效进度变化。当前边界的短亮沿随填充端移动。 |
| 链接完成 | 尾端确认后抬起一小束亮光和碎屑，完成带按原宽淡出。 |

### 未起手的连接带渐变

![未起手的连接带自身渐变参考](link-progress-gradient-reference.png)

这张局部图用于定未起手时连接带自身的小幅度渐变。渐变随带子一起移动，固定在带子的局部位置，用于表现半透明材质和轻微明暗起伏。

有效点击并保持按住时，才在底带上叠加进度填充。填充前沿使用实际进度坐标，换轨时跟随路径。整条带的世界宽度固定，完成时保持轮廓淡出。

## 连接带尺寸

**连接带的世界宽度固定。** 同轨、斜向换轨和单轨连双轨都使用同一个宽度。端点大小独立，以覆盖相邻轨道为准。带子等宽伸进两端的图层下面，由音符外壳遮住接缝。弯道让带的边线沿路径转向，按住与收尾通过亮度、填充长度和透明度表现。

工程已有底带、完成覆盖层和进度点。落地时将底带和覆盖层统一到同一宽度，将宽节点倍率从带宽几何中解耦。亮沿跟随同一进度坐标，粒子由尾节点完成事件触发。

本稿为视觉设定与状态分镜。用内置 imagegen 以用户原对战图、双轨透明态局部及等宽标注为提示，分别绘制珊瑚果冻外形、连点递减、链接带内进度和全宽淡出。
