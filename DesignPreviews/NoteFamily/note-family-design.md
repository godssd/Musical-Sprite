# Musical Sprite 音符家族

沿用普通单击已定稿的透明琥珀壳、奶油色爪印和命中回弹。飞行中先靠轮廓读出覆盖轨道，再靠数字或路径读出下一步。亮度随操作进度移动，让玩家余光也能跟上。

## 外形设定

![音符外形设定](note-family-concept.png)

上排从左到右为普通单击、双轨单击、连点。下排为同轨长按、换轨滑按、单轨到双轨的混合长按。视图用于看形状和透光。进对战时，单位尺寸、中心与轨道位置取自现有音符和节点数据。

| 音符 | 移动中怎么认 | 操作反馈 |
| --- | --- | --- |
| 普通单击 | 单轨琥珀胶囊，中间一枚爪印 | 用已落地的压缩、回弹、上行金光和碎屑作基准 |
| 双轨单击 | 一整块跨相邻两轨的高胶囊，只有一个共享爪印 | 任一覆盖轨命中，整块同步受压回弹。亮点和碎屑从实际按下的一侧起，反馈落在玩家手下 |
| 连点 | 与普通单击同量级，中央使用一个高对比余数，壳边有浅缺口 | 每次有效点击给一次短回弹，数字随有效点击扣除。回退和返回判定线沿用实际运动。末击使用完整上行光和碎屑 |
| 同轨长按 | 爪印头、连续透明连接带、实边收尾端 | 起手亮头，保持时仅判定线交点附近亮一小段。尾端完成时亮起并散出碎屑 |
| 换轨滑按 | 同一条连接带连续穿过轨道，转折处用小节点 | 光沿当前路径推进，节点在通过时给短脉冲。前方路径保持透亮，已完成段很快隐去 |
| 混合宽度长按 | 根据每个真实节点显示单轨或双轨宽度，连接带在过渡段内连续收窄或展开 | 用一股进度光走过宽度变化。在双轨范围仍以当前判定允许的任一轨跟随 |

旧谱面的小型单击沿用普通爪印外形做小尺寸版本，保留其兼容判定。缩小后优先提清爪印，边缘高光合并为较少的几笔。

## 命中分镜

![连点和滑按的动作分镜](note-family-motion-board.png)

上排演示连点余数从 4 变成 3 后，外壳受压再归位。下排演示滑按从头节点起亮，经过中间节点，最后在尾端释放。分镜固定机位便于对照三个状态。实际对战的接触光锚在判定线与当前路径的交点。连点中间拍以清楚的数字和弹性为主，碎屑集中用于收尾。

## 落地节奏

- 双轨单击沿运动轴受压，两端的跨轨长度保持清楚。以普通单击约 0.04 秒压缩、0.09 秒回弹作首轮基准。由点击轨先亮，光在同一块外壳上扩散。
- 连点中间拍以 90–120 毫秒回弹作首轮目标。数字保持正立和稳定的屏幕中心，连续到来的有效输入可以接管上一段局部反馈。末击接普通单击的收尾节奏。
- 长按、滑按共用一套头、带、尾材质。路径由实际节点、覆盖轨宽和时间生成，亮点跟着判定进度走。首次按下和尾端完成使用短瞬态，中间节点降低亮度和粒子量，以便读清下一次换轨。
- 首轮先用实际对战镜头对照双轨单击和连点，再验同轨、多节点换轨、单轨变双轨和双轨变单轨。检查密集音符、亮判定线以及前景遮挡同时出现时，余数、尾端和下一次换轨仍可读。

两张概念图用内置 imagegen 制作。外形图以现有琥珀果冻和用户对战效果图为提示，在同一地面条件下比较六种操作轮廓。分镜图以外形图和现有回弹截图为提示，固定机位比较连点递减与滑按的局部点亮。
