## 一、固定设计基准

1. 场景编辑以用户图一为底：保留地面纹理及色块、植物、石头、树桩、角色、音符、中央分界、相机与场地布局。环境只保留图一所示的背景补充和局部光影程度，不重绘成新庭院，不添加雾幕。
2. UI 造型严格以用户图三为准：宽厚但渐细的珊瑚红 / 柔蓝曲线、奶油色手绘字、叶片点缀、Combo 花草与小石头底座、相连的开口箭头环。图三作为造型母版；先前网页简化样本不作为美术依据。
3. 判定线和判定灯采用已讨论完成的方案，不重新选风格。能量槽外观与现有状态表现保持原样。
4. 背景层与地上场景件分开。过热是背后升起的循环插画布景，常态图不强行同时呈现所有状态。
5. 生成图是外观与关键帧概念，不证明 Unity 的材质、动画或图像像素级保留已经实现。

## 二、扣血：保留已有四项反馈，优化配合

### 保留的实际场景配置

| 项目 | 当前场景值 | 本轮提案 |
|---|---|---|
| 主血量下降 | 0.8 秒，先快后慢 | 保留总时长与损失可读性，使用曲线内裁切，不压扁整个图形 |
| 黄色残影 | 停 0.25 秒，再 0.7 秒消退 | 保留，在手绘色带内部显露；与真实剩余血量颜色明确区分 |
| 整条闪白 | 0.5 秒，峰值 0.9–1 | 保留闪白反馈，但把强峰值收在前 60–90 ms，后续转成薄柔光尾迹；原 0.5 秒作为总包络 |
| 整体回弹 | 1.02–1.2 倍，0.3 秒 | 小伤沿用轻回弹；大伤建议优先调到 1.10–1.14 倍，仍由伤害比例驱动，作为待比较参数 |
| 液面晃动 | 0.55 秒 | 保留，用较宽缓的单次起伏，减少高频边缘抖动 |
| HP 数字 | 立即更新 | 保留，不能因动画滞后误报当前血量 |

动作顺序：受击瞬间闪白和主体回弹 → 色带下降、液面晃动 → 叶片延后约 40 ms 跟随摆回 → 黄色损失段追赶消失。红蓝两方镜像，所有反馈以本方血条为范围。

花叶不随整条血量裁切；血条外轮廓和空槽轮廓稳定。连续伤害合并残影包络，从当前可见状态接续，不让整个 UI 多次叠加放大。回血保留平滑补充，增加填充末端的低亮度掠光，仍不触发受伤动作。

## 三、分数替代：字形接力与叶尖回声

保留图三的大号奶油手绘数字和两侧叶片。

- 加分瞬间确定真实目标值；只有发生变化的数位参与动画。
- 旧字向上移动约字高 4% 并淡出，新字从下方约 4% 处进入，整体 120–160 ms。只出现旧、新两层，不经过一串中间数字。
- 最多 1.03–1.05 倍的局部落定，不再让整个分数组 1.2 倍跳动。
- 旁边叶尖延后约 40 ms 摆动，200 ms 内归位；不每次喷粒子。
- 高频加分合并到最新目标，不排队播放；保底补分仅更新数值，叶片不作命中庆祝。
- 未变化的一方保持稳定。修复同值 SetScore 重启动画的问题属于接入步骤。

备选简化实现：保留数字立即更新，只做变化数位 1–2 px 的提落和短暂奶油高光；用于低分辨率下避免重叠字形影响阅读。优先展示前一种方案。

## 四、Combo 替代：数字、短弧、花草分层运动

造型保留图三的完整花草底座、左右短弧、COMBO 标签和粗圆数字。游戏内缩放整组以适应现有区域，底座轮廓保持低矮，不能遮住音符识别区。

- 每次 +1：数字用 35 ms 轻压到约 0.97，再在 70 ms 内回弹到 1.06–1.08，随后 100 ms 回稳。
- 两侧短弧向外展开约字宽 3%，透明度短暂提高；COMBO 标签稳定。
- 花草根部固定，叶梢延后轻摆一次，不能让整个底座跳起来像新场景件。
- 可选每 10 连击仅强化一次叶片舒展，不追加奖励文案；与过热事件重合时合并动作。
- 清零：旧数字和侧弧回收，140–200 ms 消失；底座最后稍淡出。下一次有效连击再恢复。保留当前零连击不显示数字的规则。
- 被技能削减：数字更换为较小值，短弧向内收，短暂暖色提示后恢复本方颜色；没有成功回弹。
- 保留现有动态锚点跟随，动作只放在子节点上，避免与位置更新冲突。

## 五、评价 UI 替代：手绘字与一笔短弧

使用与图三数字一致的饱满手绘字形，采用简洁文字加渐细短弧，不增加徽章、长条底板或厚黑描边。

| 等级 | 外观与差异 | 建议时间 |
|---|---|---|
| PERFECT | 奶油亮字，下方一笔本方色弧线，末端两颗很小的叶形亮点 | 70 ms 轻弹进入，停 170 ms，约 300 ms 消退 |
| GOOD | 同一字体，暖奶油色，较短低亮弧线，没有散点 | 总计约 450 ms |
| CLEAR | 奶油字配清浅青色弧线，弧线一次舒展开 | 总计约 550 ms |
| PASS | 小一档同款字与简短低亮色弧 | 总计约 400 ms |
| MISS / BREAK | 如继续显示现有失败评价：偏灰紫字、短弧收回，无亮点；BREAK 的文字映射沿用既有规则 | 总计约 350 ms |

评价在原命中区域附近短距离浮起，位移控制在字高约 10–15%，减少现有长距离向上漂浮造成的干扰。评价颜色区分等级，弧线区分红蓝方。

同音轨密集判定合并显示或更新当前条目，不堆叠长串文字；不同轨道保持独立。是否显示失败评价仍遵循当前玩法/显示设置，本轮不私自移除现有分支。图中示范 PERFECT 的峰值帧。

## 六、技能输入替代：开口环的形变与连接曲线

沿用图三箭头、开口环和连接曲线的具体轮廓。游戏右侧仍按原布局竖排三个按钮，连接曲线改为相同笔触的竖向走向，不把横向母版硬塞进场内。右侧是本地玩家输入，主题按玩家 side，而非屏幕所在侧决定。

| 状态 | 新表现 |
|---|---|
| 待机 | 奶油箭头稳定，开口圆环有手绘粗细变化；连接尾线保持低亮度 |
| 按下 | 箭头和环轻压到 0.95，再于 120–160 ms 回位；环缺口轻微闭合，不用大幅弹到 1.35 |
| 有效前缀 | 当前环的一小段扫成奶油亮色；对应角色保留已有 SkillSelect 呼应 |
| 完整释放 | 连接曲线从刚输入的环向两端依次亮起，三个环轻舒展，350–450 ms 收尾；最多两三颗小叶点缀 |
| 输入错误 | 保留明显错误反馈：三个环同步偏暖红一次，环尾收回并轻摆；不做成功释放的连线高光 |
| 超时 | 已输入的短弧痕迹在约 160 ms 内消退 |
| 技能可用 | 有合法候选时环旁小叶舒展一次，常态保持克制；无需持续脉冲 |

错误反馈在红方通过动作和亮度同时区分，不仅依赖变红。箭头始终可读，视觉缩放不改变点击区域。已有角色技能选择/释放动作继续保留。

候选技能可能有不同序列长度，因此不新增固定三格输入进度。技能冷却继续在对应角色能量槽表达，不给三个共用箭头套一个虚假的公共冷却环。

## 七、已确认的判定线与判定灯

效果图必须包含：

1. 常态轻薄连续线段及低对比音轨引导，无实体灯壳与黑色厚框。
2. 点击时整段中性白色柔光，并有向场内延伸的大面积低透明渐变。
3. 有效命中时近白亮芯偏本方红 / 蓝，亮度强于按下；音轨上下两侧边缘同时发光。
4. 近端边光有细亮芯和宽软光，向场内逐渐减弱、变窄并消失；暖色过渡粉紫，冷色过渡蓝紫。
5. 不把一个音轨画成硬矩形框，不添加从判定灯向场内横穿的独立中央光条。

整局概念图只选少量轨道显示命中峰值，其余保持常态，以便同时看清两种状态。中央分界不在本轮重设计范围。

## 八、能量槽

不更改现有素材、锚点、两段结构、黄白充盈闪烁、释放白闪、缩放脉冲和冷却进度。它们已经承担明确的信息，不加入重复的 UI 动画。

## 九、接入边界与交付

- 本轮交付全局静态效果图和动效关键帧板。关键帧用于评审造型与节奏，真实时长以本文为准。
- 当前 BREAK 在各系统中的处理存在差异；接入时先对照设计规则澄清，不借 UI 迭代改变判定或 Combo 计算。
- HP 使用当前场景参数作为起点；方案中的修改值单独存为新表现配置，方便逐项对比。
- 动效采用独立通道：数值、主体回弹、叶片跟随、残影、局部高光，各通道同一时刻只有一个有效包络。
- 保留原图地面与场景件应在最终 Unity 合成时使用原资源精确完成；生成概念图尽量保留，但不能承诺逐像素一致。
- 使用内置 imagegen，根据用户提供的原场景图、已选 UI 母版和判定光参考生成。完整提示词见同目录 `battle-ui-approved-v2-prompts.md`。
