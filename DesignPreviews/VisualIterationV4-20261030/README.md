# 视觉迭代 V4 · 2026-10-30

依据新录屏 QQ20261030-8958.mp4 与本轮重发参考实施。仅处理血条排版/颜色/变化光层、Combo、入场、判定带发光本体。基础 PNG 曲带、头像框、数字字形与 Combo 位置保留；未保存 SampleScene，未调整用户已移动的场景件。原 UI 继续隐藏保留。

## 实装

### 血条与颜色

- HP 字高从34调整为42，分数恢复接近76的固定字高；均下移贴近曲带，分数保持主要信息层级。
- HP 按真实字形排布，但为同长度血量预留固定宽度，避免326、222、86等血量切换影响分数字高或锚点。
- 固定六位长度的血条不伸缩，分数仍向红方左侧/蓝方右侧在既有曲带范围内增长；数字平滑跟随。装饰点在空间紧张时平滑收紧，保持与 HP 不重叠。
- 奶白减少黄色，红色略向参考的珊瑚红校正。两侧空槽维持独立低饱和团队色；基础原画不重绘。
- 实黄/实绿变化区新增共享贴形内亮层、薄亮缘与外晕；移动刻度保留更亮、更大、溢出的光。黄色和绿色只换颜色，图形与追赶机制一致。外晕采用环形软采样和端部渐消，避免矩形截口及重复横条纹。实色本体保持不透明。
- 已确认的红方右扣、蓝方左扣，先白闪，再实色停留和追赶，危险暗闪，刻度归零后爆开/结算逻辑保留。

### Combo

- 旧数字快照移到实时数字的同级、下层，不继承新数字弹跳。新命中立即更新实际 Combo，同时让旧纸片继续完成短暂灰化/淡出，不再直接 Cancel。
- 为0–9制作独立的上下主撕裂路径：`Assets/Resources/BattleVisualV11/ComboTearPaths.json`。纸屑锚点依据现有字库透明轮廓提取，常态图片不变。
- 主体保留大块，边缘切碎程度减小，补少量细碎纸屑。纸边按连续边界绘制，替换按各三角片重描导致的虚线感。
- 提前灰化与淡出；0.23秒时主体 alpha 低于0.5并变暗，0.30秒完成消失。COMBO标题和小装饰在主撕裂阶段保持，再同步退出。
- 快速新命中时，旧片在约0.055秒内进一步灰化、退到新数字后方；不阻塞输入，不延迟实际计数。重开/同步和禁用仍立即清理快照，零连击不凭空播放。

### 入场

- 身份图形从整体贴形白光开始，避免只先出现一颗孤立光点；分数初始不显示。
- 推进头、已生成区域和边缘/外围光分别处理；头部更亮，后方能量稍回落，加载轮廓仍完全来自原 PNG。
- 完成时头像内容与团队色同步还原，终点碎光具有大小差异、亮芯及弱外晕。

### 判定带

- 发光本体宽度绑定已有判定带实际宽度，整段亮起；内部偏白、保留薄队伍色缘，端点与直线轮廓明确。
- 外围柔光独立软化，上下横向色光继续采用独立核心衰减与色相渐变。保留四轨、红蓝统一结构及按下/成功/失败路由。
