## 1. 屎屎停帧：资源名称缺失与状态机无回退共同造成

`CharacterAnimator.SlotTable` 请求：

- `Aibo_2_Shit_04_Play_Superfever`
- `Aibo_2_Shit_08_Target_Superfever`

当前屎屎 Spine JSON 没有上述动画。普通和过热循环/命中存在，但超级过热状态没有匹配资源。

控制器 `SetLoopState` 先把逻辑当前循环改成超级过热。若角色当时正在播一次性命中，代码等待它结束；之后 `Update` 因目标循环名字解析为空而提前返回，连“单次播完回循环”也被跳过。于是单次命中已经完成、骨骼停在最后姿势；后续超级过热命中同样因缺动画被拒绝。

隔离 Unity 实测：

1. 普通过热循环正常播放。
2. 在过热单次命中期间切入超级过热。
3. 当前轨保持 `07_Target_Fever`、`loop=False`、`complete=True`。
4. 再推进0.4秒，应用后的骨骼姿势不变；超级过热命中被拒绝。
5. 切回已有普通循环后恢复。

这一机制解释了为什么同侧只有正在播单次动画的角色可能停住，而其他角色继续动作。不能把它简单当成音轨网格或渲染性能问题。另有屎屎命名不匹配：代码要 `09_Hit`，资源是 `08_Hit`；代码要 `10_Dizziness`，资源是 `09_Dizziness`；胜利资源为 `16_Victory01/02`，并无通用 `16_Victory`。

建议：按角色做明确名称解析/别名；超级循环暂缺时回退到其已有过热循环、超级命中回退已有过热命中；不要把 Select/Special 等无关动作擅自当成超级过热。状态机即使请求缺失动画，也必须保留有效回环恢复路径。补测所有角色在单次动画中进入/退出过热、超级过热、受控和技能状态。

## 2. 扣回血存在实质时序错误，单次小样未覆盖

`FullRibbonHealthMotion.Change` 每次事件都重置 Elapsed。当前白闪0.09秒、停留0.10秒，合计0.19秒后刻度才移动。

实测每0.15秒扣一次：6次后实血目标已经从100%降到81.6%，但 Cursor 仍为100%，一直未进入移动。连续回血同理：目标70%，刻度仍停在30%。这是密集事件导致的等待饥饿；不应解释为有意延迟扣除。

反向打断也会跳变：一次损血追赶中 Cursor 为65.62%，触发回血到75%时，Cursor 被立即改到50%。黄绿颜色分类看似正确，但刻度位置不连续，因此用户看到血条忽然回缩、再推进。

建议拆开：实血目标、最新受变动闪光区、累计待扣/待回区、连续移动刻度。新事件更新目标与短闪光，不反复重启已经开始的等待/移动；反向事件需要连续重定向或明确的区间合成，不能为切颜色直接跳刻度。测试应加入0.05/0.10/0.15秒密集事件和反向事件，保留已确认的左右方向与归零后结算。

录屏的连续血条裁切20–25秒主要是扣血；没有把它当成完整回血实拍证据，回血异常由相同运行模型的独立复现支撑。

## 3. 扣血白闪缺少稳定峰值与亮度层级

10点伤害仅约565×10/326=17.3个逻辑像素宽，实际Game显示更窄；白闪仅0.09秒，且连续事件不断改写区间。当前黄绿内亮、外围光和刻度光又同时叠加，容易出现“白峰值不突出、黄色一小块闪烁、刻度光抢主戏”的读感。

应先解决事件时序，再分配亮度：局部变化区一记清晰的团队色白闪 → 稳定实黄/实绿 → 明确的刻度追赶。黄色与绿色共享贴形光层，不能靠提高全条亮度补救；危险状态继续暗闪，不能和受伤白闪混用。

## 4. 过热需要同时看分数火苗和后方布景

分数后火苗实际存在，但固定等距排列、近似等宽/同类摆动仍偏模板化。普通到超级主要加两侧火苗和高度，层级与节奏尚不足；不能为了增强超级过热继续挤占数字上方布局。应以小火苗轮替、横向展开、少量火星与受控亮度区分级别，熄火沿原位置缩灭。

后方布景不再是早期被严重压扁的矮条，资源也确实不同；但暖色布景与分数火焰堆在同一视线区域，干扰HUD信息。当前循环本质为静态透明图的轻微UV摆动和花灯明暗，不足以形成参考要求的分层循环布景。后续需围绕现有机位做枝叶/花灯的局部分层运动和层次控制，保持根部稳定，不恢复大面积雾，不改原地面和角色。此次未以“静态循环像素有变化”作为视觉达标证据。

## 5. Combo：连续性已改善，但纸感与可读阶段仍不足

新命中不再直接清掉旧快照，这是已落地的改善。剩下的差距是实际显示尺寸下切口/纸边太细、主块错位偏小，碎片与音符、地面和辅助线混在一起；快速重新命中时，旧片额外灰化退让又进一步缩短可见阶段。

应保持常态字形、位置和纸片撕碎方向，强化主裂口的实际像素可读性、主体块层次和短暂的清晰撕裂阶段。新数字立刻响应，旧片通过短距离错位和层级让出中心，不能只靠继续降低alpha隐藏冲突，也不应延长成遮挡操作的大片爆炸。

## 6. 音轨：保留实体轮廓，细调色彩层次

这版判定带实体比上版明显接近参考，四轨结构无需再推倒。后续重点是缩小持续纯白覆盖比例，让亮芯偏暖白/冷白，薄色缘、队伍色外晕、远端低饱和过渡分层；多轨同时亮时控制共享边界重复叠加，保留地面可读性。不能再次把发光体整个模糊掉。
