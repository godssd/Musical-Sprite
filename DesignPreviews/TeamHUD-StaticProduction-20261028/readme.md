## 统一装配规则

layout-v1.json 在素材目录中，定义每侧 720×200 示例坐标、固定血槽尺寸、六位分数保留区和字形槽位。分数采用稳定字高/字距，红方右边界固定向左加位，蓝方左边界固定向右加位；基础血条不跟随位数变长。六位以外规则本轮不新增，不改实际计分上限。

蓝方几何使用镜像后的同形 alpha，剩余血靠右，从左侧扣除。头像内容可替换，预览暂用空白占位，未生成定制角色头像。文本不随几何镜像。

血槽 fill、空槽、黄/绿、闪光与常态小刻度必须使用同一 alpha，内侧卷钩包含在有效血槽内；外侧身份月牙与头像框是固定装饰，不混入生命进度。常态小刻度通过窄截面与本 alpha 相交得到，不能直接摆一根高竖光棒。预览里的窄白线就是此方式合成，正式动态边界尚未绑定。

## 生产检查与限制

原始拆层图由图像工具从锁定参考提取生成，仍是第一版素材，不应宣称与参考像素完全相同。生成源的三排并不严格等高，打包使用已检查的分区，修复了按均分网格裁断头像圆框的问题。环内及轮廓外散点通过连通域清理，保留原主体与抗锯齿留边。

数字/HP 原图裁片外加 8px 透明 padding，避免图集边缘串色。导入关闭 mipmap 与有损压缩，保持原图尺寸、Clamp、双线性。未修改现有运行代码、旧图片、当前样式 asset、SampleScene、判定参数或 Combo 位置；原旧 UI 继续保留。

本轮只做图片结构检查与组装预览，没有运行 Unity 对局验证，火焰、闪光、入场推进、残血暗闪和死亡时序均还未接入。
