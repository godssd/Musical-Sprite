# 最新动效修订：以本轮用户说明为准

2026-10-28。常态素材制作伴随记录，覆盖旧预览 V5/V6 关于即时刻度的冲突描述。此文件不是已实现的代码行为。

1. 红方剩余血从左向右，扣血从右侧减少；蓝方镜像，扣血从左侧开始，剩余血靠右。两侧使用同一套血槽 alpha，不能为了效果重画血槽。
2. 扣血：变化区间闪一次偏队伍色的白光，带柔和光晕；红方暖红白，蓝方冷蓝白。同队治疗与受伤闪色相同。
3. 随后损失区间变成实色暗黄色，短暂延迟；刻度从旧显示边界跟随黄色尾段回落，黄色通过边界缩短而消失，不透明度淡出。数字可以先同步真值，但刻度不再采用 V5 的立即跳到新 HP 位置方案。
4. 回血：先产生新增绿色实色区间，带同队白闪；刻度随队伍色实血追上、绿色区间缩短而移动，直到绿色消失。不能显示两根刻度。绿色不是整条改色。
5. 非满血常态保留小刻度，完全裁切在血槽内；变化时变大、提亮，仍贴合局部截面。满血不要求常驻刻度。
6. 残血暗闪：压暗→回常态，最高为常态亮度，不做增亮白闪或强光晕，以免混淆治疗。
7. 致死扣血也先白闪、变黄色、延迟移动；尾段与刻度到零点后，刻度消失并在零点爆炸熄火，接对局失败表现。不能伤害触发第一帧就爆。后续接入时需协调现有立即发出的失败事件和失败画面/转场，保证不被早转场截断；不得只靠头像或分数判断失败。
8. 普通过热小火苗循环，超级过热稍向分数两侧扩展，控制高度不挤占 HP、头像与布局；两者均增加少量向上飘起的火星，保持简约，不恢复密集粒子。
9. 断过热从当前姿态收缩扑灭，已有方案保留，做好循环退出衔接。
10. 入场初始无 UI、无分数；白光核心贴合所有已加载 UI 的 alpha 轮廓，附柔和近距离光晕。加载前沿额外高亮，显示推进位置，但不新增高竖光棒或扫描矩形。未加载区域空白。达到终点转回默认色瞬间出碎光与短声，无“叮”字。

本轮仅制作常态与共用遮罩素材，未声称上述动效已完成。原有 UI 不删除、Combo 位置和判定参数不改。
