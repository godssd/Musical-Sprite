# 战斗 UI 视觉提案（2026-10-22）

本轮只做视觉预览，尚未替换 Unity UI 资源。`battle-ui-kit-v2.png` 是单独的组件造型板；`battle-ui-ingame-v2.png` 是放回场景后的比例和可读性预览。生成图里的局部场景细节和文字笔触不作为精确交付素材。

## 共用语言

米白色手绘高光、薄的红/蓝色偏移笔触、暗紫色半透明底和少量不规则边缘；外形克制，数字优先清楚。红蓝双方形状、视觉重量一致，通过颜色和左右镜像区分。游戏场内保留手绘笔触，HUD 不参与后续的场景卡通滤镜。

## 蓝圈标注的四类元素

1. **血条**：保留长胶囊比例和已有液面、受击残影、闪白逻辑。外框改为偏米白的细手绘线，液体增加一条柔和高光，空槽用暗紫色。红方从左向右填充，蓝方从右向左填充；数值仍落在有色填充区域内。
2. **顶部数字**：这是 `ScoreDisplay` 的分数。用统一的浅米白数字形态，红蓝各有很轻的偏色底影；短暂加分时才轻微弹动，常态不持续发光。
3. **场内数字**：这是 `ComboDisplay` 的连击数。减小黑描边和底影厚度，改用浅米白字面、红/蓝笔触偏移与少量节奏短线。保留当前位置和跟随中线的定位。Miss 时仍按原逻辑清空，不为 Miss 单独设计浮字效果。
4. **方向按钮**：这是 `SkillInputUI` 的三个技能序列输入键，顺序为左、下、右。视觉面采用暗紫色半透明圆角方块、米白箭头和侧色角笔触；底层触控区域保留现有 160×160 参考尺寸。按下时局部发光和轻微缩放，错误反馈短暂转红。

## 判定线与判定灯

保留现有斜置判定线的位置与结构；灯是其中一段判定线的状态，不另加实体灯泡、黑色底座或粗外壳。常态只有细色线；按下时整段略增亮并向场内铺开低透明度渐变；非 Miss 命中时整段更亮，中心米白向红/蓝过渡，远端带轻微色相变化并柔和消失。`battle-ui-kit-v2.png` 底部表示常态、按下、命中的亮度递进；最终场内渐变应比静态示意更柔软，避免可见三角边。
