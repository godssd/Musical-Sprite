# 整段曲带 HUD：运行接入与审查

完成核查：2026-10-29。目录日期保留本批开始日期。新血条已默认接入 ScoreManager 的运行入口，进入 SampleScene 的 Play 即可出现；不需要往场景手动添加新组件。

## 本批实现

- 固定长度整段曲带，六位分数区；红方右对齐、增加位数向左展开，蓝方镜像。字高稳定，变化时数字短暂反馈与位置平滑接续；血条不随位数伸缩。
- 损血：仅变化区间按队伍色闪白并带柔和光晕，随后保留实色暗黄色，停留后追赶缩短。刻度跟随黄色尾段边界，不在触发瞬间跳到目标。
- 回血：同队同闪色，新增实色绿色区间，队伍色与刻度追赶至目标后绿色消失。反向事件取消过期区间，重建对应颜色，旧尾段不会在结束回调中重新出现。
- 非满血常态小刻度在槽内；真正移动时加宽、提亮，并在原轮廓外显示柔和溢光。所有填充/闪光使用同一原始血槽 alpha，内侧卷钩不会永久亮起。
- 蓝方剩余血靠右，损血从左边扣除；对应刻度和颜色区间镜像。
- 濒危只压暗至常态，最高不额外增亮；进入/退出阈值有回差。
- 小火苗按实际 FeverManager 状态循环，超级过热增加高度/覆盖及少量火星，退出从当前状态收缩扑灭。效果位于分数后面，布局不变。
- 入场初始无 UI、无示例分数。贴形白光带高亮推进前沿和柔和近距离光晕，完成后恢复默认色、终点出碎光并播放短提示音；没有“叮”字。
- 归零完成黄色追赶后，刻度消失并从零点爆开熄火。GameManager 的对局停止仍即时生效，只把失败结果展示延迟到零点爆点，避免盖住过程。重开取消待触发失败、清除残留并重播入场。
- 默认头像从批准原图提取、移除了旧边框；头像内容可替换并裁切到框内，不需要定制表情或战斗动画。

## 测试入口

Unity 菜单：**Tools → Musical-Sprite → V11 → 08 Full Ribbon HUD And FX**。

窗口使用实际运行组件、真实图片与同一 Shader，提供双侧同时预览：起始/目标、损血、回血、入场、濒危、归零、过热、超级过热、扑灭。可在动效中再次点击变化目标检查接续。预览使用独立场景，不修改 SampleScene。

参数资产：`Assets/Resources/BattleVisualV11/FullRibbonHUDStyle.asset`。窗口“选中参数资产”可直接定位。主要字段已标注中文。

| 参数 | 当前起点 | 用途 |
|---|---:|---|
| 常态刻度宽度 | 1.5 | 静止时收在血槽内的小刻度 |
| 移动刻度宽度 | 3.5 | 变化中的亮芯粗细 |
| 移动刻度溢光强度 | 1.5 | 向外发亮的程度 |
| 溢光范围 | 9 | 血槽外光晕宽度（设计坐标） |
| 白闪时长 | 0.09s | 仅变化区间的一次闪光 |
| 黄绿区间停留 | 0.10s | 白闪之后的停留 |
| 损血/回血追赶 | 0.28/0.45s | 停留后的尾段移动时间 |
| 濒危最低亮度/周期 | 0.28 / 1.25s | 压暗幅度与间隔 |
| 入场加载/变色 | 0.65 / 0.12s | 白光推进与完成收束 |
| 入场前沿高亮强度 | 1.8 | 生成进度头部高亮 |

`avatars[0/1]` 是红/蓝自定义图片；运行时也可调用 `FullRibbonBattleHUD.SetTeamAvatar(side, sprite)`，采用等比覆盖并圆形裁切。布局缩放、屏幕边距、火苗高度/两侧扩散、火星数量和声音强度也在同一资产中。已有判定线参数未改。

分数实际计分不受显示组件限制；本批按用户六位要求将数字显示封顶为 999999。当前没有新增玩家头像选择界面。
