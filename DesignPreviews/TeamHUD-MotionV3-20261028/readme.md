# HUD 动效 V3：固定长度与火花充能

2026-10-28，待用户审查的效果图；未修改游戏代码。内置 imagegen，实际提示记录见 prompts.md。静态造型沿用已批准的大头像整段曲带。

## 三张效果图

- 01-fixed-six-digit-layout.png：1～6 位固定字高；血条始终按六位长度；红方分数右边界固定、向左展开，蓝方镜像。跟随分数起点的小笔触移动，血条两端、末端卷钩和固定叶片不移动。正式跨位约 0.16～0.20s 平滑移动相关字位/装饰，不改变血条宽度。
- 02-health-tick.png：损血黄虚血与回血绿虚血沿用；只闪本次损失/新增区间。实血边界用清晰发光刻度，变化时提亮并移动，常态降亮但保持清晰。濒危改为血条间隔亮起。
- 03-flame-and-charge.png：过热在分数背后闪火花，超级过热加强；断过热扑灭余火；归零在剩余实血边界短促爆裂熄火；入场亮黄填充从零到满，终点光点与短促叮声，整条一亮转回队伍色。取消胜利专属效果。

## 对旧方案的覆盖

此前 motion-design-v2.md 中“血条随位数延展、支持七位”的部分作废，改为本稿固定六位长度；濒危、过热、归零、入场和胜利规则以上述新需求为准。头像内容可替换，头像和外框不参与战斗动效。总分仍为真实计分，六位以上显示策略尚待单独确定，不能自行限制实际得分。

## 示意误差与正式制作要求

图为静态关键帧，不能证明逐帧移动速度、闪动频率或声音；“叮”为声音触发点标注，不是要在游戏显示文字。百分比和逐格填充位置是示意，准确区间依据真实 HP/maxHP。

生成图的常态刻度仍较亮，正式效果需与变化峰值拉开亮度。黄色虚血在图中部分被白闪覆盖，制作时必须在白闪之后保留原有黄尾追赶。部分空槽内侧尾钩残留队伍亮色属于生成误差，必须跟随整段空槽遮罩；外侧身份月牙与头像框可以保留队伍色。归零瞬间剩余填充应迅速收清，不能把图中残留红段当成常态设计。

红蓝复用同一效果结构和强度，布局镜像。火花保持在分数后方、避开头像和 HP；字形保持奶油色与可读性。血量变化不缩放整套 HUD。入场黄色只覆盖实际曲带，不生成独立外部光线；非满血开局的展示衔接仍需确认，不改真实生命值。
