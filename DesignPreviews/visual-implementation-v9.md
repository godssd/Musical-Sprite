## 2. 分层撕裂的落地规则

### 空间关系

- 以整组数字的可见范围为中心建立分片分布，不把每个数字平均切成同样的几段。
- 越靠中央，分片越大、切口越少，保留主要笔画的识别性；向外逐步增加切分密度，最外缘形成短而细的纸片状残片。
- 中间层必须存在，避免只有两个完整大字加一圈小粒子。分片面积参考可从大 / 中 / 小约 1 : .3 : .05 开始调整；这只是制作初值，不是宣称生成图已经精确满足的测量值。
- 在原字形覆盖的区域中裁切，先形成大块，再对外圈继续细分。小片沿原外轮廓的撕扯方向分离，数字外缘相应缺失。
- 单字、双字、多位数都按实际排版计算。总片数设置上限，不能每增加一位就增加一整套粒子；小尺寸下不可辨的小片直接省略。

### 运动与消失

- 中央大块：位移最小，较慢灰化 / 淡出，最后留下短暂的主要笔画轮廓。
- 中间碎片：向外拉开的距离与转角适中，连接中央与外缘的动势。
- 外缘小片：略早分离、外移较明显、较早淡出；不形成烟雾、粉尘、爆炸或飞遍画面的纸屑。
- 所有片使用原数字纹理的 UV 和 Alpha，边缘是薄的哑光撕口，不是白色发光描边、金属折面或石块断面。
- 红蓝同一数字使用同一分片模板与运动参数，只有灰化前的队伍色不同；最终灰色一致。

初始关键帧仍为：0.00 秒原态、0.05 秒拉扯、0.13 秒撕裂灰化、0.23 秒淡出、0.30 秒完全消失。实际切分与节奏以真实游戏尺寸核对，不能把整张生成板当作运行时动画资源。

## 3. 简化后的常态 Combo

结构收敛为：小号 COMBO 标题 + 大号数字 + 两侧短弧 + 一角少量叶片。

- 不加新的底板、石台、浮岛、下划线平台或厚阴影来替代被删除的地面。
- 去掉装饰地面后重新紧凑排版，数字仍是视觉中心，原场景透过 UI 保持清楚。
- 成功回弹主要作用数字和短弧，小叶片仅轻微跟随；不再有整片花草底座运动。
- 失败时标题 / 短弧 / 小叶片直接淡出，只有数字参与分层撕裂；末帧整组隐藏。
- 旧 Combo=0 时不生成碎片或装饰；新连击立即显示新数字，旧退场不能覆盖新状态。

## 4. 资源与代码计划相应调整

- 从待制作 Combo 资源清单中删除泥地、石块、花丛底座；保留少量独立叶片和短弧。
- 更新分片生成参数为从中心向边缘递增的切分密度，替代 V7 / V8 中简单“均匀少量大块”的制作方式。
- 同一数字裁切结果可缓存复用；片对象池有上限。使用显示数据快照生成退场片，不修改真实 Combo 值的更新时机。
- V9 图仍是造型预览：第二轮已强化大块主体和细碎边缘；工程中还须控制中等片的过渡与真实字形面积，不能通过额外撒屑伪造层次。

## 5. 验收重点

1. 第一眼能读到中心大、边缘小，大小对比在实际 HUD 尺寸仍清楚。
2. 外缘小片确实从字形分离，中央不是碎得最密的区域。
3. 拆除装饰性地面 / 石头后，常态画面更简洁，但与已选手绘 UI 风格一致。
4. 两队同形、无连击不播、新命中能打断旧退场、末帧无残留。
5. 原场景地面与场景件没有因 UI 装饰简化而改变。

以上为后续实施标准，本轮未执行运行检查。
