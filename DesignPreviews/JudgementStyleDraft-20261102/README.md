本轮推进下一任务的可审查产物。内置 imagegen 生成，两版原图均保存。最新版为 rating-flat-draft-v2.png。

六种文字：PERFECT、GOOD、CLEAR、PASS、YES、MISS。沿用奶油手绘文字和短队伍色笔触；BREAK 继续映射 MISS，不另造评分类型。当前为美术审稿图，未覆盖现有游戏评价、未标为正式生产图集。

动效建议：PERFECT 轻压回弹后柔和消退，GOOD 同族较弱反馈；CLEAR/PASS按原评分语义区分；MISS短促收束。成功与失败事件各自表现，长条合法连续判定不去重吞掉；发生同帧多条判定时避免不受控叠字。
