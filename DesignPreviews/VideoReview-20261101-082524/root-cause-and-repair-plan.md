## 一、静态素材与排版不是同一份母版

实际素材来源：`DesignPreviews/TeamHUD-StaticProduction-20261028/parts-source.png` 与 `ribbon-source.png`，经独立部件提取和alpha清理后进入 FullRibbonStaticV1。它们不是锁定整稿逐层拆出的相同像素；叶片轮廓、叶脉、月牙厚度自然存在差异。

原 layout-v1 使用720×200坐标、505×48血带、64高分数、36高HP；现参数为760×200、565×48、86高分数、48高HP，并继续叠加独立宽度比例。这里的565是为固定六位数长度所作适配，不能简单恢复505，但也没有按同一母版统一重排。

FullRibbonBattleHUD.LayoutNumbers：HP相对血带矩形顶部排；分数通过三次近似中心线排；头像/月牙/叶片又是各自固定坐标。不是“所有信息共用一套已核准的布局”。Make中还用单色最大通道乘队伍色重映射红蓝素材，不能默认与原稿色感一致。

修正：

1. 以已选“整段曲带+放大头像”原稿为唯一静态母版；本次图2/图5仅定义入场，不能倒过来改变常态形状。保留固定六位数长血槽、红向右/蓝向左的规则。
2. 优先从母版拆取真实叶片、月牙、头像框、点饰和曲带；没有干净分层的边缘需要按原轮廓清理/描摹，不再自由生成替代造型。保留纸感、笔触、轮廓比例。
3. 在母版中标注每一部件的可见alpha边界、锚点、统一缩放比例、HP基线、分数基线、留白。取消为单个部件硬凑的拉伸。
4. 排版使用同一母版坐标；数字1–6位只改变数字组与随行点饰的位置，血槽长度/形状不变。六位最宽数字先作容量验证，短数字不得借机改变全组大小。
5. 同画幅、同底色、相同数字做50%叠图与差分：轮廓、间距、比例、颜色先通过，再制作任何新动效。另检查实际游戏区域安全边距，不能用录屏外框作缩放依据。

## 二、血条光效是渲染结构错误，不能仅靠系数恢复

FullRibbonHUD.shader的主体采用普通透明混合。当前效果：将区间染白、用条带alpha模糊取得外光、叠一个窄刻度。条带内部不透明区域的外光贡献被核心覆盖；扩光发生在整个条带形状上，闪光/虚血区间又在扩光后按横向范围裁切。结果更像浅色条、平行边缘，不是参考中独立的高亮光头。

TickArc只有2.5单位的横向偏移，条带截面使用三次中心线和固定截面宽度近似。它能定位刻度，不能重建参考中的弧形尖光及上下溢出。单纯增加tickGlow/半径，无法同时得到细核心、弧形尖光和大而软的晕。

修正的四层结构：

- 底层：锁定母版原曲带，颜色和形状不随效果改动。
- 实血/虚血层：同一精确alpha遮罩；黄/绿实色，允许同等级的内部亮带和贴边光，但不靠降低透明度“虚化”。
- 光核心层：独立弧形刻度，常态小且在槽内；移动时用同一中心位置切换/过渡为尖弧形亮核心并上下溢出。沿实际曲带截面采样位置与上下边界，取代固定宽度近似。
- 外光层：独立软晕与尖光贴片，控制近场色光、远场衰减；显示在主体之外。Overlay UI须自行绘制这层，不能指望场景Bloom自动处理。

先把核心区间遮罩做好，再在该区间外扩软晕，避免先模糊整条再硬切区间。损血和回血共用几何/亮度结构，只换黄绿颜色；队伍白闪分别有暖红/冷蓝倾向。

保留规则：HP实际值即时改变；损血区白闪一次→实黄色→延迟后刻度从旧端追到实际值；回血先出现实绿色→刻度从旧端追到新值。常驻刻度不因普通低血量消失；满血隐藏；归零时追赶结束、刻度消失后爆点和失败。红方从右端扣，蓝方从左端扣。小额变化也必须能读到独立光头，不能只靠变化区宽度撑开光效。

连续同向变化继续追赶，反向变化单独验证不瞬移、不短暂显示反色。旧逻辑通过并不代表光效还原。

## 三、入场有白色，但缺少沿造型运动的光头

### 用户补充：刻度必须单独制作和验收

当前刻度问题不止亮度不足：

- 常态和移动共用一条由横向距离函数生成的窄条，只换宽度及光强，缺少参考中的弧形尖端轮廓。
- 核心绘制受血条alpha限制，溢出部分主要是条带alpha扩光，不能形成清楚的上下尖弧和柔和外光。
- 刻度截面由近似中心线、固定宽度和2.5单位偏移决定，没有使用当前位置的真实曲带上下边界；位置对了不等于形状贴合。
- 开局真实血量已是满血，TickVisible按满血规则为0；加载虽然有白色前沿，却没有独立的加载刻度。血量进度与加载进度混用了可见性规则。

解决时将血量刻度与加载刻度分开驱动，复用同一套经确认的光核心与外晕素材/着色结构：

| 状态 | 位置及运动 | 造型及显示 |
|---|---|---|
| 常态非满血 | 当前已稳定血量边界 | 小刻度完全收在曲带内，保持清楚；满血隐藏，归零在爆点触发时消失 |
| 损血 | 旧显示血量端点→新实际血量端点，沿黄色虚血收缩方向运动 | 启动时平滑放大、变亮，上下溢出尖弧；不是普通小刻度直接粗放拉长 |
| 回血 | 旧显示血量端点→新实际血量端点，沿绿色虚血消失方向运动 | 与损血同几何、同亮度级别，换对应颜色；结束后收回常态尺寸 |
| 开局加载 | 揭示到血带时，从血带起点沿曲带扫向终点；红向右、蓝向左 | 使用独立加载进度，不能被满血规则隐藏；白亮核心、队伍倾向/暖白柔光随前沿运动，不额外出现第二条竞争的光线 |
| 加载完成 | 先确实抵达终点，再释放碎光 | 转常态色的同一完成节拍，刻度融入终点高光后快速收掉；满血最终不留常驻刻度 |

准确位置由母版血条遮罩采样，记录每个进度的中心、上下边界；小刻度裁切于槽内，变化态核心和外晕允许在独立层溢出。刻度形状要根据实际截面适配，不可将一根直杆任意旋转后视为还原。血量事件白闪不能吞没刻度光尖，也不能令刻度突然跳至新目标。连续事件、反向事件的接续沿用上一节规则单独验证。

### 用户补充：完成碎光改为前向、大而明确

当前FullRibbonAccentGraphic的burstOnly使用全圆角度生成7个菱形，等价四面八方散射，与本次要求不符。

- 以加载终点前进方向为主轴：红方向右、蓝方向左，先采用主轴两侧约25–40度的前向扇区，不向后做全圆爆散。
- 发射点锁在曲带实际终点/加载刻度中心，加载到达前不能提前喷出。
- 主要碎光尺寸先按现有效果约2–3倍试制，飞行距离约1.5–2倍；采用少量大碎光+少量小光点，不能仅增加细屑数量。
- 用白亮核心、柔和外光及大中小尺寸层次保证识别；起步快、前向减速、最后淡出，避免均速漂浮。
- 左右采用同一局部坐标动画镜像方向，保持相同视觉尺寸和强度；明确限制最大占位，避免遮住HP与分数。
- 尺寸、扇角、距离为首轮制作值，验收依据是原速游戏画面中完成节拍明确可读，不把参数倍数当作最终验收。

当前统一按屏幕横坐标step揭示，身份图形由Identity直接整体显示，移动光头是指数距离函数；不是沿UI可见形状的统一加载距离。头像到文字之间的空间、不同部件之间的断开，都会使感知速度忽快忽停。

修正：同一母版附一张加载进度遮罩/距离场，定义身份→月牙→曲带终点的加载路径；白色主体、窄高亮前沿、宽柔光晕使用同一个进度。头像可短促启动，但不长时间单独白停。前沿先快扫出、末段减速蓄亮，完成瞬间转常态色并发碎点；不提前显示分数，不渐显整组，不改母版轮廓。以本次图2/图5做同进度关键帧对照。

## 四、Combo节奏与可见度一起设计错了

ComboDisplay和场景中均保留0.30秒。ComboTearGraphic中，open和separate分别使用两段SmoothStep；后一段仍一直增加位移到结束，并非快速分离后阻尼停住。约0.13–0.14秒开始淡出，0.156秒后继续乘变暗，0.282秒时亮度倍率降到0.48；0.23秒时alpha也只约0.4。叠在彩色地面、音符和场景件上更难辨认。新命中还会叠加灰化与0.65倍率。

此前ComboReview明确断言“0.23秒alpha不大于128”，等于把过早隐去写成通过条件。它验证了旧时间表，没有验证玩家能否读出撕碎。不能再把这项PASS当视觉验收。

建议新节奏（待实机关键帧审查，替代旧0.30秒限制）：

| 时间 | 表现 |
|---|---|
| 0–0.05秒 | 小幅快速拉扯，数字轮廓可辨 |
| 0.05–0.12秒 | 主裂口快速打开，边缘小纸屑跟出 |
| 0.12–0.38秒 | 主碎片沿初始速度方向阻尼减速，保留大块轮廓；慢慢灰化，不同时压暗+淡出 |
| 0.38–0.60秒 | 停稳后的残余纸片渐隐，细屑比主块更早退场 |

位移用单一连续的阻尼曲线，透明度独立控制。中心大块、边缘细碎沿用已选造型；不改字形、Combo位置。总时长建议先0.60秒，不能只拉长现有两段SmoothStep。新Combo立即正常增长，旧碎片独立继续；通过灰化/分离距离分清新旧，避免立刻压低到不可见。还需定义短时间多次断连时残片复用上限，避免积累。

## 五、过热火苗也是造型替代问题

现用FullRibbonAccentGraphic临时贝塞尔网格画3/5簇火苗，弱火height20、强火30，再叠正弦起伏。与确认稿中具体火尖、根部连贯和向两侧展开的形态并不同。只改高度会在“看不见”和“遮分数”之间摆动。

应按已选平面小火苗重建可复用的2–3色火焰轮廓，用少量循环帧/受约束形变实现，先定普通/超级两张峰值形状及最大占位，再定循环。火在分数后方，超级主要加宽覆盖、增加侧火与少量火星，不向上无限增高。不新增场景过热布景重设计。

## 六、执行顺序与验收

1. 静态母版重建：先只交常态1/4/6位数字、左右队伍、满/半/残血叠图。未对齐不进入动效。
2. 刻度/虚血：先提交固定血量、单次变化下的近景关键帧，再覆盖5/10点小额、连续和反转事件。四层结构对应同一血槽母版。
3. 入场、Combo、过热分别提供实机100%速度动图和带时间的关键帧，不用浏览器近似样本替代游戏结果。
4. 最后在完整对局检验遮挡和可读性；组件测试只证明逻辑，不能代替画面对齐。

验收目标是还原设计，不是继续自由改风格。静态轮廓/排版要逐像素对照；光晕要在相同底色和缩放下对照强弱、范围与衰减；时序必须对照已批准的实机时间轴。小尺寸参考截图本身没有完整时间信息，不能凭一张图声称整段动效已100%还原。

保留旧UI以便回退，不动角色、地面、场景件、中央能量墙和Combo位置。
