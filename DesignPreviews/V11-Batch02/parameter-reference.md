# 判定 UI 工具：参数说明与窗口使用

日期：2026-10-24。适用于 V11 判定参数资产及审查窗口。

## 窗口怎么放大

- **00 Judgement UI Parameters** 现在直接打开独立参数窗口。内容随窗口高宽扩展；保存、搜索和分类固定在顶部，参数列表使用剩余全部高度。
- **01 Judgement UI Review** 提供“参数与画面 / 只调参数 / 只看画面”。选“只调参数”即可让参数区占满剩余窗口，同时隐藏预览操作。
- 混合模式中，窄窗口上下排列、宽窗口左右排列；拖动中间分隔条可分配面积。不再固定为 220 像素。
- 六组参数可折叠，可按分类筛选，也可搜中文名称、英文变量名或用途。悬停名称显示解释，点右边“?”在面板下方展开帮助；“显示每项说明”会在每个参数下持续显示解释。
- 本轮仅修改编辑器界面，没有替换用户已调好的 RailStyle.asset 数值；“建议起点”仍需主动点击，支持 Undo。

### 控件重叠修正

移除以临时 GUILayout 矩形创建 BeginArea 的混合布局，参数与预览改为统一自动布局，避免 Layout 阶段的无效尺寸使控件挤到左上角。分类改为下拉选择，不再将七个分类按钮横向挤在参数栏里。预览未载入时显示加载提示；调参本身无需载入预览。

## 红色感叹号是什么

它来自工具的 Error HelpBox。旧代码只检查 failure != null，空字符串也会显示红色错误图标，形成没有说明的空红框。当前读取到的相关 Editor.log 没有提供可归因的实际预览异常，不能把空红框直接当成游戏错误。

现在只有非空错误文字才会显示红框，真实预览失败会包含具体原因，并提供“重试加载 / 复制错误详情”；没有载入预览则显示普通提示。即使预览失败，也可单独调参和保存。

## 数值的共通规则

- **世界单位**：实际场景尺寸，不是屏幕像素。相机和分辨率会影响看起来有多少像素。
- **半宽**：从中心线到一侧的距离，完整宽度约为两倍。
- **比例**：0–1 的相对位置或长度；先扣除中央留白再计算可用长度。
- **不透明度**：0 为透明，1 为不透明；不等于光的亮度。
- **倍率**：1 为基准，增大通常更强；与同层透明度和衰减共同作用。
- **指数**：纵向指数越小，远端保留越多；横向收束指数越小，光铺得越宽。
- **命中总时长** = 峰值停留 + 衰减时长。静态冻结预览看不出时长差别，需要开启“播放衰减”。

## 常态判定带与辅助线

| 中文名称 | 原英文名 | 具体作用与调节方向 |
|---|---|---|
| 判定带宽度 | `railWidth` | 整条平面判定带的完整宽度，单位为世界单位。增大更粗；不直接改变光晕宽度。 |
| 辅助线半宽 | `guideHalfWidth` | 常态五条辅助线的半宽。完整宽度约为此值的两倍；越大越容易看清四轨。 |
| 段间留隙半宽 | `segmentGap` | 相邻判定段的总空隙约为两倍此值；0 表示常态段相接。 |
| 辅助线延伸比例 | `guideReach` | 判定带到中央分界可用距离的比例。0 不延伸，1 接近中央留白边界，不改变真实判定位置。 |
| 常态判定带不透明度 | `idleOpacity` | 0 透明、1 不透明。调高更实；若颜色仍暗，应调亮度或常态颜色。 |
| 常态颜色亮度倍率 | `idleBrightness` | 1 为原颜色亮度，0 为黑色，超过 1 提亮。只作用于常态判定带。 |
| 辅助线不透明度 | `guideOpacity` | 常态辅助线近端的基础透明度，远端仍叠加纵向衰减。 |

## 范围与强度

| 中文名称 | 原英文名 | 具体作用与调节方向 |
|---|---|---|
| 前向光延伸比例 | `lightReach` | 按下内侧渐变和命中上下边光的几何长度，相对半场可用距离。实际可见长度还受衰减影响。 |
| 中央分界前留白 | `seamPadding` | 先从可用半场长度扣除的距离，单位为世界单位。越大，延伸光越早停在中央分界前。 |
| 判定段光晕半宽 | `railHaloWidth` | 判定带两侧光晕的覆盖半宽。增大扩大柔光范围，亮度由强度参数另调。 |
| 上下边光晕半宽 | `edgeHaloWidth` | 命中时沿音轨上下边界的光晕覆盖半宽。增大让边光更柔、更有面积。 |
| 按下判定段亮度倍率 | `pressStrength` | 空按 / 按住时整段的亮度。命中另有独立倍率，通常应比按下更亮。 |
| 命中判定段亮度倍率 | `hitStrength` | 非 MISS 命中时整段亮度，1 为首版基准。超过 1 增强发光，不改变持续时间。 |
| 命中上下边亮度倍率 | `edgeStrength` | 音轨上下两条共享边的整体亮度，不改变判定段。相邻命中仍取最大包络。 |
| 按下内侧渐变强度 | `pressWashStrength` | 按下时轨道内部大片渐变的包络强度，与按下渐变不透明度共同作用。 |
| 按下渐变不透明度 | `pressWashOpacity` | 按下时内侧大片渐变的基础透明度。过高会盖住地面细节，不控制细亮边。 |
| 命中渐变不透明度 | `hitWashOpacity` | 命中时轨道内部染色的基础透明度。可比按下更强，仍需保留地面可读性。 |

## 渐变曲线与色相

| 中文名称 | 原英文名 | 具体作用与调节方向 |
|---|---|---|
| 纵向衰减指数 | `falloffPower` | 沿光长的亮度衰减约为 (1-距离比例)^指数。越小远端越亮，越大越集中在判定带附近。 |
| 尾部羽化开始位置 | `tailFadeStart` | 0.7 表示最后 30% 额外淡到零。增大推迟尾部羽化；前面的纵向衰减仍存在。 |
| 边光远端收窄比例 | `edgeTaper` | 越大，上下边光越往远处越窄；0 不额外收窄。光的中心路径始终笔直。 |
| 远端色相混合量 | `hueAmount` | 0 保留近端队伍色，1 更多过渡到远端颜色。色相和透明度分别控制。 |
| 色相变化起点 | `hueStart` | 从光长的哪个比例开始向远端颜色过渡。越小越早变色。 |
| 色相变化终点 | `hueEnd` | 色相过渡完成的位置，按光长比例计算。需大于起点；不控制透明度。 |

## 细芯与外围柔晕

| 中文名称 | 原英文名 | 具体作用与调节方向 |
|---|---|---|
| 判定段细芯强度 | `railCoreIntensity` | 判定带中间细亮芯的强度，外围晕光由柔晕强度控制。 |
| 判定段柔晕强度 | `railHaloIntensity` | 判定带外围柔光强度。要更柔，可配合加宽光晕，不必只提高此值。 |
| 判定段细芯收束指数 | `railCorePower` | 横向收束指数：越大细芯越细，越小越宽。它不是亮度系数。 |
| 判定段柔晕收束指数 | `railHaloPower` | 越小外围光晕铺得越宽，越大越集中；范围仍受光晕半宽限制。 |
| 上下边细芯强度 | `edgeCoreIntensity` | 音轨上下边界里细亮线的强度，与外围柔晕独立调整。 |
| 上下边柔晕强度 | `edgeHaloIntensity` | 上下边细亮线周围柔光的强度。提高面积感，注意别冲白地面。 |
| 上下边细芯收束指数 | `edgeCorePower` | 越大边界细芯越细，越小越宽。不改变直线路径和延伸长度。 |
| 上下边柔晕收束指数 | `edgeHaloPower` | 越小外围晕光越铺开，越大越集中，与上下边光晕半宽共同决定柔和程度。 |

## 时间

| 中文名称 | 原英文名 | 具体作用与调节方向 |
|---|---|---|
| 命中峰值停留（秒） | `hitPeakHold` | 命中保持最亮状态多久，再开始衰减。0 表示立即衰减。 |
| 命中衰减时长（秒） | `hitFadeDuration` | 峰值后的退出时间。总命中时间 = 峰值停留 + 衰减时长。 |
| 松开衰减时长（秒） | `releaseDuration` | 松开后的输入光退出时间，不控制命中光；仍按住时 Hit 结束会回到按下态。 |

## 颜色

| 中文名称 | 原英文名 | 具体作用与调节方向 |
|---|---|---|
| 红方常态颜色 | `idleRed` | 红方平面色带的原色，还会乘常态亮度。透明度请调专门的不透明度参数。 |
| 蓝方常态颜色 | `idleBlue` | 蓝方平面色带的原色。几何和时间仍与红方一致。 |
| 红方命中光晕颜色 | `hitRed` | 红方命中外晕和内侧染色的近端队伍色，白亮芯另有颜色参数。 |
| 蓝方命中光晕颜色 | `hitBlue` | 蓝方命中外晕和内侧染色的近端队伍色。 |
| 红方细芯颜色 | `coreRed` | 红方最亮细芯的近白色，减少黄色分量可得到更中性的暖白。 |
| 蓝方细芯颜色 | `coreBlue` | 蓝方最亮细芯可用轻微冷白，不必涂成饱和蓝。 |
| 远端过渡颜色 | `farColor` | 红蓝共用的远端目标色，配合色相混合量与变化起止位置使用。 |

## 建议调节顺序

1. 常态：先宽度 / 颜色亮度，再辅助线长度与透明度。
2. 冻结单轨命中：先延伸比例，再纵向衰减和尾部羽化。
3. 柔和程度：先光晕半宽，再柔晕收束指数，最后柔晕强度。
4. 层级：对比常态、按住、命中，确保命中最强。
5. 打开播放衰减：调整峰值停留、退出时长，比较相邻命中。
6. 点击“保存参数”。退出 Play 后仍保留在参数资产中。

本轮验证：编辑器 C# 离线编译通过；41 个运行时参数均有对应帮助条目；已移除固定 220px 参数高度与空字符串错误显示。窗口实际交互与渲染仍需在 Unity 中审查。
