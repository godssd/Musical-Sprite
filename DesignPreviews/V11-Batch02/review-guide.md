# V11 第二批：可保存的判定参数与回血小样

日期：2026-10-24。第一批用户实机反馈：方向正确，需要开放系数细调。本批集中开放参数，并推进曲带主体 / 绿色回血技术小样。

## 1. 判定 UI 参数入口

**便利性更新（同日）：**菜单 00 打开全高度独立参数窗口；菜单 01 支持“只调参数”和可拖动分隔条。已修正手动分区导致的控件重叠，分类改为下拉选择。参数已显式中文化，加入搜索、逐项说明与 ? 帮助。完整解释见 `parameter-reference.md`。本次界面修正保留已调数值。

**Tools → Musical-Sprite → V11 → 00 Judgement UI Parameters**

选中的配置是 `Assets/Resources/BattleVisualV11/RailStyle.asset`。它是实际游戏和 01 审查窗口共同使用的持久资产，不是临时运行对象。配置同时驱动红蓝两侧，几何和时间相同，颜色可以分别设置。

也可以打开 **01 Judgement UI Review**，选择“参数与画面”。即使关闭“播放衰减”、冻结在峰值，参数变化仍会反映到小样。宽度等几何修改会重建小网格；颜色和强度也同时刷新，无需重新进入 Play。

编辑完成后点击参数区顶部 **“保存参数”**，退出 Play 后保留。支持 Undo。“建议起点”是手动按钮，不会自动覆盖你的调整。

建议先冻结“单轨命中”调范围和软边，再打开衰减调时间，最后返回常态 / 按下检查层级。

| 想调整什么 | 对应字段 | 方向 |
|---|---|---|
| 常态色带太细 / 暗 | 判定带宽度、常态颜色亮度倍率、不透明度 | 增大；亮度与不透明度分开 |
| 常态轨道不清楚 | 辅助线半宽、不透明度、延伸比例 | 增大；半宽是世界单位 |
| 按下 / Hit 不够亮 | 按下判定段亮度倍率、命中判定段亮度倍率、命中上下边亮度倍率 | 分别调；大于 1 可增强亮度，不仅夹紧 alpha |
| 光晕范围小 | 判定段光晕半宽、上下边光晕半宽 | 增大，颜色不透明度无需同步增大 |
| 光芯太粗 | 细芯收束指数 | 增大使细芯更细；减少使其更宽 |
| 光晕硬 / 太紧 | 柔晕收束指数、柔晕强度、半宽 | 减小指数 / 增大半宽，配合强度 |
| 光太短 | 前向光延伸比例、辅助线延伸比例 | 增大；中央分界前留白继续生效 |
| 远端太快消失 | 纵向衰减指数、尾部羽化开始位置 | 减小指数，延后羽化起点 |
| 上下边越远越窄 | 边光远端收窄比例 | 增大后收窄更多 |
| 内侧渐变偏弱 | 按下内侧渐变强度 / 不透明度、命中内侧渐变不透明度 | Press 与 Hit 分开 |
| 远端色相变化不明显 | 远端颜色、混合量、起点、终点 | 用微紫等远端色；不要只提高白光 |
| Hit 一闪就没 | 命中峰值停留、命中衰减时长 | 分别控制稳定峰值与退出；总时长为两者之和 |
| 松手退得太快 | 松开衰减时长 | 增大 |

未开放轨道数量或自由改判定锚点：这些仍由真实四轨 Spawner 提供，避免调美术时改变玩法几何。运行对象中旧的重复几何字段已隐藏，统一在配置资产中调节。

## 2. 下一步已接入的 HP 行为

原 `HPBarLiquid` 新增绿色治疗层，复用原 Fill 的形状 / 贴图，主条和 HP 数字继续由现有血量事件驱动。保留原黄色损血虚条、闪白、回弹与波动参数。

- HP 真值与数字继续即时更新；队伍色实条约 .55 秒追上新增目标，绿色区间收缩消失。
- 连续治疗从当前显示位置接续，绿色范围向新目标扩展，不回到旧起点。
- 治疗中受伤：立即清过期绿段，按最新真实伤害显示黄色损血区间。
- 伤害未追平就治疗：不重置主条到过期数值；绿色覆盖真实新增区间，并在本次过渡中退出。
- 连续伤害保留当前黄色高水位，不跳回已经退掉的旧高水位。
- 满血无实际增加 / 同值更新不伪造治疗；初始化和无动画基线清理残留。
- 图形层只表现变化，不给角色加血、不改伤害量，也不增加护盾逻辑。

回血开关、颜色、追平时长位于原 `HPBarLiquid` 的“回血”参数组。

## 3. HP 曲带小样入口

**Tools → Musical-Sprite → V11 → 03 HP Ribbon And Healing Review**

点击“载入 / 重建曲带小样”。上方红条、下方蓝条镜像。可播放回血、扣血、连续回血、治疗被伤害打断、伤害后立刻治疗，也可以在动画中反复改变目标。

这是**曲带几何和区间动画技术小样**，尚非最终完整手绘 HUD。未在游戏中提前替换整套 HP 美术、数字字库、分数和装饰。它使用程序曲带网格验证任意形状下的实条 / 虚条接合，不把矩形填充或带背景概念图冒充正式切图。

现有 **Tools → Musical-Sprite → HP Bar FX Preview** 也已支持起点小于目标的回血和追加目标；选原血条可以查看实际原形状上的反馈。Play 中不再由编辑器和运行时重复 Tick 动画。
