## 生成图的限制与审查结论

- 第一张主要看固定分数起点与随位数增长的尾端。第二张受面板宽度影响，六/七位示例字号略有变化，正式组件必须共用相同字高，不能照图按格缩放。
- 第三张回血结束的 HP 数字被画成绿色；正式设计保持队伍色，绿色只用于新增虚血区间。图中的 +82/-130 是辅助示意，HP 增减小字是否启用应作为可关选项，不额外压过总分。
- 第三/四张一些空血尾端残留亮色，正式制作必须让有效尾钩与整段血槽共享进度遮罩。只有头像框和外侧身份月牙属于固定队伍装饰；归零不能把身份装饰一并误当作血量清掉。
- 面板之间细小的头像、曲率与字距差异为生成误差，不属于动效。头像及框的尺寸、位置、颜色全程保持，只有内容可替换。
- 这些图片说明效果方向与关键姿态，不能证明逐帧速度连续或实际 Unity 接入；下一阶段需基于拆层素材与布局组件验证。

本轮没有改动游戏代码、场景、现有参数或 Combo 位置，没有执行运行时测试。
