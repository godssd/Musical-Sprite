# V9 单一上扬趋势：素材与显示修订

日期：2026-10-27。按用户红色引导线修正，不再使用图像生成模型重绘这条轮廓；采用 SVG 贝塞尔矢量母版，透明 PNG 由同一条路径抗锯齿导出。红蓝使用同一母版镜像换色。

## 关键几何

长线中心控制点为 (280,280)、(700,260)、(1120,190)、(1540,155)。三个相邻 X 差均为正、Y 差均为负，因此长线整个参数区间内严格向右 / 向上推进，不存在水平停顿或中途回落。上边缘和下边缘分别为单段三次曲线，厚度由 28 平缓收至 20 源像素，没有多次鼓起。只有末端允许回卷。月牙与长线接口共享切向斜率，避免折点。

素材：`Assets/Art/UI/V11-Handpainted/CurveV9/`，含红蓝与中性 PNG、对应 SVG 和 curve-layout.json。PNG 1900×380，Full Rect / Bilinear / 无压缩 / 无 mipmap；源母版与生成脚本 build-frame.ps1 同步保留。SVG 是可精确编辑的轮廓源；本批不是内置图像生成结果，不需要生成提示。

## 为什么同步修改显示

旧 Sliced Image 对三段分别缩放，拉伸段与端部之间的横向导数不连续，曲线即使在源图中平滑，也可能在实际显示时形成斜率突变。

新增 `SmoothHeaderFrameImage`：以固定高度确定原始比例，在中段用五次 smootherstep 平缓分配增加的宽度。分配函数在端部的第一、第二导数都为零；源图 X 到目标 X 的映射保持递增，不会凭空产生上下反转。端部在常用长度范围内不横向拉伸。低于整个素材原比例宽度的极端配置统一压缩 X；仍不产生反转，但端部会变窄。默认 2 / 4 / 6 位分数不触发此情况。

只改装饰线渲染：HP 主条 / 绿色回血 / 黄色损血、分数计分与轻微弹动、Combo、判定参数、角色与场景不动。
