# 星港拓荒

一个独立的 Unity 6 桌游原型项目。玩家与自动对手争夺新星港的建设先机，通过探索、建造和贸易积累声望。

## 打开与运行

用 Unity Hub 打开本目录（Unity 6000.0.82f1）。首次打开后，在菜单 **Board Game → Create Starter Scene** 创建并打开原型场景，然后点击 Play。

## 当前规则原型

- 2 名玩家（你与自动对手），共 8 轮。
- 每轮各有 2 个行动点，可探索、建造或贸易。
- 探索获得木材和粮食；建造消耗资源并获得声望；贸易将多余物资换成金币。
- 每轮触发一张公共事件；8 轮结束后声望最高者获胜。

这是从零开始的独立项目，与父目录的 Musical Sprite 项目分开。
