## 1. 模式优先级阶梯

```mermaid
flowchart TD
    A[游戏主界面] --> B[练习模式]
    B --> B0[P0 AI 对战]
    B --> B1[P1 单人练习]
    A --> C[剧情模式]
    C --> C2[P2 第一章节]
    C --> C4[P4 后续章节]
    A --> D[快速对战 P3]
    A --> E[排位模式 P3]
    A --> F[讨伐模式 P3]

    style B0 fill:#1D9E75,color:#fff
    style B1 fill:#0F6E56,color:#fff

    style C4 fill:#0C447C,color:#fff
    style D fill:#888780,color:#fff
```

> 优先级：**P0 AI 对战 → P1 单人练习 → P2 剧情第一章 → P3 快速/排位/讨伐（置灰）→ P4 剧情后续**。

## 2. AI 对战整体流程（P0）

```mermaid
flowchart TD
    START[主界面] --> ENTRY[练习模式弹窗]
    ENTRY -->|选 AI 对战| A[Step A 乐队规模选择]
    A -->|确认| B[Step B 玩家角色选择]
    B -->|GO 选满| B2[Step B' AI 阵容选择<br/>初始全员随机 / 规模=玩家]
    B2 -->|GO| C[Step C 歌曲选择]
    C -->|GO| D[Step D 真实双方对战]
    D -->|战斗结束| R[结束弹窗]
    R -->|再来一局| D
    R -->|更改乐队规模| A
    R -->|更换角色| B
    R -->|更换歌曲| C
    R -->|退出练习| EXIT[主界面]

    style D fill:#1D9E75,color:#fff
    style R fill:#BA7517,color:#fff
```

## 3. 单人练习整体流程（P1）

```mermaid
flowchart TD
    START[主界面] --> ENTRY[练习模式弹窗]
    ENTRY -->|选 单人练习| A[Step A 乐队规模选择]
    A -->|确认| B[Step B 角色选择 + 皮肤]
    B -->|GO| C[Step C 歌曲选择]
    C -->|GO| D[Step D 个人练习战斗]
    D -->|曲结束| LOOP[自动重新循环<br/>HP 不重置 仍≥1]
    LOOP --> D
    D -->|暂停| P[暂停层 6 项]
    P -->|继续战斗| D
    P -->|调整机器人参数| D
    P -->|回歌曲选择| C
    P -->|回角色选择| B
    P -->|回乐队规模选择| A
    P -->|退出个人练习模式| EXIT[主界面]

    style D fill:#0F6E56,color:#fff
    style P fill:#BA7517,color:#fff
```

## 5. 随机人物卡解析与去重

```mermaid
flowchart TD
    OPEN[开局 / 再来一局] --> RESOLVE[RandomRosterResolver 解析]
    RESOLVE --> POOL[本侧已拥有角色池]
    POOL --> FILTER[剔除本侧已选具体角色 + 已被其他随机槽占用]
    FILTER --> PICK[每个随机槽取不同角色]
    PICK --> FIX[单局内结果固定]
    FIX --> BATTLE[进入战斗]

    style RESOLVE fill:#534AB7,color:#fff
    style BATTLE fill:#1D9E75,color:#fff
```

> 去重范围仅限**本侧**；每次开局重新随机；同局内不漂移。
