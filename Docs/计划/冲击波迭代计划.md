## 0. 目标

用**两道红蓝对冲的半透明拱形冲击波**取代现有"粉杠"（`CenterLine` 立方体），作为双方领地 / 对战态势的视觉表现。

**这是美术表现迭代，不是玩法改动**：游戏逻辑（粉杠位置驱动、分数机制、扣血机制）一律不变，只替换表现层。粉杠淘汰，由两道互推墙取代。

---

## 1. 核心约束（铁律）

1. **逻辑不变**：冲击波墙位置仍由 `BattleCenterLine.currentX`（分差 Lerp 驱动）决定；地面 `_CenterLineX` 同步逻辑一行不动。任何阶段都不得为了"表现更好看"去改写分差→位置的计算。
2. **规则使用铁律**：本计划涉及 `GroundEdge` / `GrassFringe` shader、`BattleCenterLine.cs`、`NoteMover.cs` 等既有规则载体，改动须遵守 `Docs/规则/INDEX.md`——牵扯规则不得擅自违背，需商榷先汇报，仅用户明确强调改规则才可破例。
3. **每阶段验收**：P0→P8 严格顺序，每阶段在 Unity 验收确认后再推下一阶段。
4. **可回退**：旧粉杠先隐藏（不删），留作备份防不可挽回；新实现出问题可即时回退。

## 2. 现有粉杠逻辑（事实源，不重造）

文件 `Assets/Scripts/BattleCenterLine.cs`（已逐行确认）：

- **驱动**：`diff = ScoreManager.GetLeftScore() - GetRightScore()`；`targetX = diff * pushPerHit`（`pushPerHit = 0.001` → 分差 5000 移动 5 单位）；`currentX = Mathf.Lerp(currentX, targetX, dt * smoothSpeed)`，物体 `x = currentX`。
- **地面**：`groundMaterial.SetFloat("_CenterLineX", currentX)`（红蓝面积随粉杠位置）。草丛 `grassMaterial` 同步。
- **命中累加**：`NoteSpawner.cs:781` 调 `RegisterHit(side, accuracy)`，命中时累加 `_leftScore/_rightScore`（引用 ScoreManager 时改用真实分差）。
- **扣血独立**：`ScoreManager.cs:337` 注明"粉杠随真实分差移动，此处只改分数/血量，不改粉杠"——血量是一套独立系统，不驱动粉杠位置。
- **与音乐无关**：纯分数机制驱动，无任何 Conductor / 节拍耦合。

## 3. 两道互推墙映射（已与用户确认）

```
红墙区间  [-6, currentX]      蓝墙区间  [currentX, +6]      中缝 = currentX（复用 _CenterLineX）
对峙  currentX ≈ 0  各占半场、中缝互顶
前进（红领先）  currentX 右移 → 红墙前沿右推、蓝墙被挤右退
后退（蓝领先）  反向
```

地面 `_CenterLineX` 逻辑一行不动，只把"粉杠立方体"换成"两道从中缝向两侧延伸的半透明拱形墙"。

**#4 视觉包装约定**：逻辑位置仍由分差 Lerp 决定（不变）；"前进方短时突然变大一分、把对方逼退一段后回对峙"是**视觉层 offset**——`diff` 快速拉大时让前进方墙瞬间膨胀再回落，制造打击感，不持久改写 `currentX`。

## 4. 效果设计总览

| 阶段 | 表现 |
|---|---|
| 开场（演出） | 角色开场动画 → 两波从 ±6 发射 → 中央对撞定型 → 之后 Conductor 起播（与音乐**无强绑定**，纯过场，只要在播音乐/音符前完成即可） |
| 对峙 | 双方波等大、中缝互顶，循环（轻微波动） |
| 前进 | 分差拉大→相应墙向对方推进；视觉上前进方短时膨胀逼退对方后回对峙 |
| 后退 | 反向 |
| 扣血 | 受击墙做**视觉回退抖动**，不持久改 `currentX`（逻辑不变） |
| 结束 | 见 §6（两种结束方式） |

## 6. 两种结束方式

- **方式 1 歌曲结束**：全部音符发射完毕 → 游戏强制结束，分高者获胜。**无额外演出**（自然停）。
- **方式 2 击杀**：对方血量归零 → 直接获胜。获胜侧冲击波给予**最后一击变大很多**，将对方推出场外（此时 `currentX` 锁推至对方判定线外，**不再受扣血回弹机制影响**），场面全部被自己方场地覆盖。获胜者可选择：
  - **立刻结算获胜**；或
  - **继续完成歌曲**后以最终分数获胜。

> 击杀演出（P8）是独立结束分支，仅方式 2 触发；方式 1 不进入 P8。
