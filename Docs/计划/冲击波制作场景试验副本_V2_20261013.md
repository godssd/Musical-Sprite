# 冲击波试验副本 V2

## 视觉分工

- 原 `WALL.fbx` 仍是红蓝双方各自的厚墙主体，保留模型轮廓、卷曲的两端和预览运动逻辑。
- 墙面专属 Shader 只负责明暗分面、由迎击面向后方移动的宽能量色带，以及很窄的后缘透明变化。降低原版整片高亮和持续发光的外轮廓。
- `SandboxShockwaveArt` 在制作场景生成三个相互独立的网格层：两端能量扫片、短宽尾迹与地面弱光、断续结构笔触与少量碎片。大幅超出墙体的形态由新层承担。
- 两端扫片的根部沿着墙体卷曲的端部，越过模型边界后收尖。碎片先沿端部移动，随后向本方后侧剥离。
- 红色的尾迹与弱光只在红方一侧；蓝色只在蓝方一侧。尾迹限定在中间音轨之间。

## 当前限制

V2 已写入制作场景试验副本对应的脚本、Shader 与独立材质。Unity 项目自动导入了改动；脚本单独编译通过。由于窗口捕获接口在激活 Unity 时超时，本轮尚未得到 V2 的游戏画面，扫片在镜头中的宽度、层间遮挡与透明叠加仍需在 Unity 画面中判断。

本轮没有改动主对局场景、原 `WALL.fbx`、共享冲击波控制逻辑及碰撞火花触发参数。
