1. Unity 菜单 **VFX/2** 构建 `Assets/Scenes/VFXSandbox.unity`（builder 会先清场）。

## 4. 四轮修复（★踩坑教训，别再犯）

### 第一轮：素材与颜色
- 参考的**烟是 AlphaBlend**，不是 Additive。
- 参考的**颜色全在 colorOverLifetime 梯度里**，startColor 基本是白/灰。URP 的 `_ColorMode=Additive(1)` 会忽略顶点色 ⇒ 必须自写 shader（URP 里根本没有这个 keyword，只保留 `_SURFACE_TYPE_TRANSPARENT`）。
- `ParticleInstancing.hlsl` 在 URP 17 不存在，别 include。
- 老 Unity 5 格式：PS class ID = **198**（不是 114），模块名 `ColorModule`（不是 `colorOverLifetime`）。

### 第二轮：喷射朝向（烟往哪飞）
- 参考 7 个层的 Transform 自带 **绕 X 轴 −90°**，把喷射主轴从 +Y 掰到 **−Z**，正对参考 demo 相机。
- 我一度误判"相机在 +Z 侧"把它删了 ⇒ 烟全朝天。
- 后来又误设 `aimMode=1`（动态对准主相机）：俯视相机在头顶 ⇒ 又变成朝天烟柱。
- **结论：俯视锁视角用 `aimMode=0`（照搬 −90°）**，侧视/过场才用 1。

### 第三轮：补齐参考漏掉的 4 个模块（决定性）
只对齐 Initial/Shape/Emission/Size/Color 五个模块是不够的：

| 参考模块 | Unity 6 对应 | 哪些层 | 参数 |
|---|---|---|---|
| ClampVelocityModule | `limitVelocityOverLifetime` | 6 层 | circularSmoke/smoke: limit 0.5~1.2、dampen 0.4；smokeUp: 0.5~1.2、dampen 0.2；inner_fire: 1.0/0.1；floaters: 0.5~2.0/0.1；debris: 3.0/0.1 |
| UVModule | `textureSheetAnimation` | inner_fire、fire_floaters | **fire.psd 是 2×2 精灵图**（4 个火焰变体），`useRandomRow=true`、cycles=1 |
| RotationModule | `rotationOverLifetime` | 6 层 | 仅 Z 轴随机自转（弧度/秒） |
| CollisionModule | `collision` | firey_debris | World、bounce=1、`lifetimeLoss`=0.5 |

- ⛔ API 坑：`NoiseModule` 是 **`octaveCount`** 不是 `octaves`；`CollisionModule` 是 **`lifetimeLoss`** 不是 `energyLoss`，且 `dampen`/`colliderForce` 是 **float** 不是 MinMaxCurve。
- 序列帧不需要改 shader（Unity 在 CPU 端把 UV 烘进顶点，shader 用 TEXCOORD0 采样即可）。

### 第四轮：烟尘观感的「俯视适配」（主动偏离参考，已批准）
**关键事实**（脚本扒 ColorModule 确认）：参考三个烟层的 Gradient `m_NumAlphaKeys=2`，两帧 alpha 都是 **1**
⇒ **参考的烟全程不透明，根本不淡出**。它看着"先亮后透"只是因为**颜色在寿命前 10% 从亮黄 (1,0.949,0.655) 急速掉到中灰 (0.368)** + size 缩小 —— 那是侧视 + 暗背景的观感。
我们是**俯视 + AlphaBlend**，照抄就变成一整片实心灰圆片。

于是主动加了两件事（见第 5 节参数）：**HDR 起始橙黄 + alpha 衰减曲线**，以及**分轴限速压低上升**。

## 5. 烟尘当前可调参数（Inspector：`BombExplosionTest` → BombExplosion 组件）

### 「烟尘颜色（先亮后透 · 俯视适配）」
| 参数 | 默认 | 说明 |
|---|---|---|
| `smokeStartColor` | **(1.6, 1.05, 0.35)** | 刚发射的颜色，HDR >1 才发光（Bloom） |
| `smokeMidColor` | (1.3, 0.5, 0.05) | 5% 寿命处退成的橙 |
| `smokeEndColor` | (0.368,0.368,0.368) | 尾巴的灰（想偏暖改 0.45/0.42/0.40） |
| `smokeColorMidTime` | 0.05 | 变橙的时间点 |
| `smokeColorEndTime` | 0.10 | 变灰的时间点（调大 = 橙黄持续更久） |
| `smokeAlphaFade` | 空 | 留空用内置默认 `1→0.92(15%)→0.72(35%)→0.45(60%)→0.22(80%)→0`。点开可自己拖（**只调下半排 alpha 标记**） |
| `enableSmokeAlphaFade` | true | 关掉 = 回到参考原味（alpha 恒 1） |

### 「烟尘上升钳制（俯视适配）」
| 参数 | 默认 | 说明 |
|---|---|---|
| `enableSmokeSeparateAxes` | true | 分轴限速；关掉 = 回到参考的整体限速 |
| `smokeRiseLimitMin/Max` | **0.35 / 0.5** | Y 轴速度上限，直接决定上升高度 |
| `smokeHorizontalLimitMin/Max` | 0.5 / 1.2 | X/Z 轴，沿用参考 |
| `smokeClampDampen` | 0.45 | 超限时把速度拽回的强度 |

**微调速查**

| 现象 | 调什么 |
|---|---|
| 烟还是升太高 | `smokeRiseLimitMax` 0.5 → 0.3 |
| 水平扩散变弱了 | `smokeHorizontalLimitMax` 1.2 → 1.8~2.2 |
| 橙色不够久 | `smokeColorEndTime` 0.10 → 0.25 |
| 起始不够亮 | `smokeStartColor` 分量整体拉高（>1 是 HDR） |
| 烟太"扑脸"/太散 | 确认 `aimMode=0`；或调小 `smokeUpSpeedMin/Max`、关 `enableSmokeUp` |
