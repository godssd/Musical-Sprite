# 冲击波制作场景试验副本实现记录

日期：2026-10-13。

## 入口

建议打开 `Assets/Scenes/VFXSandbox_PaintedTrial.unity`，它保存了本次完整试验副本，避免当前已打开的旧场景在编辑器中重新保存时覆盖外部文件修改。`Assets/Scenes/VFXSandbox.unity` 的磁盘文件也已放入同一试验副本。层级中的 `ShockwaveArt_Trial` 为新效果，原 `ShockwavePreview(Clone)` 处于隐藏状态，可显隐切换对照。主游戏场景未接入试验效果。

## 试验内容

- 保留试验副本原有 `WALL.fbx`、墙体手动 Transform、预览器位移和缩放逻辑。
- 两面墙分别使用 `ShockwavePaint_Red`、`ShockwavePaint_Blue`。广幅三通道灰度笔触遮罩驱动表面流动、辅助流纹与局部侵蚀；新 Shader 使用各自独立色阶及固定结构亮边。
- 新组件 `SandboxShockwaveArt` 在真实模型弯曲轮廓上绘制结构线，生成靠近墙体的短宽光带、局部后向柔光以及沿轮廓运动后脱离的少量双层色片。
- 每方的后向光带与柔光只进入自己的半场。试验副本关闭旧全局场景染色，避免双方色光交叉；原对照组参数保留。
- 试验副本没有旧 `ShockwaveTrail`；新 `ShockwaveVFX` 中 `enableDrift=false`，`enableSpark=true`，碰撞火花仍由原预览器触发。

## 调整入口

- 试验根 `ShockwaveArt_Trial`：`sandboxAdvance`、`sandboxOffset` 观察不同位置与倍率。
- `SandboxShockwaveArt`：`structuralEdge` 控制结构线，`shortWake` 控制短光带，`rearGlow` 控制后向柔光，`shards` 与 `shardTravelSpeed` 控制色片。
- 两个新材质：`_FlowSpeed`、`_FlowStrength`、`_Erode` 与四个色阶。碰撞火花参数在试验副本的 `ShockwaveVFX` 上。

## 核对范围

新增 C# 脚本已使用 Unity 同版本的 Roslyn 编译器和项目程序集编译通过，两份场景的内部引用也已静态核对。当前机器已有 Unity 实例占用本项目，新的批处理 Unity 实例无法打开该项目；桌面画面读取请求超时，因此尚未取得可靠的 Game 视图截图与 Shader 运行画面。打开场景后应优先检查 Console、观察红蓝墙随 `sandboxAdvance` 放大时的亮边贴合、四轨道可读性，以及色片沿两端弯曲方向移动是否符合示意。
