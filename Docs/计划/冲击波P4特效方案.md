## 1. ① 碰撞火花（Clash Spark）

### 设计意图
两道墙在中缝对撞时，撞击点迸射火花。是「互顶」这件事最直接的视觉反馈。

### 位置与方向（用户明确指定，不可改）
- **位置**：只在中缝那条线上（不是整条拱顶，也不是墙全身）。
- **方向**：从中缝线**朝 ±Z 两侧**射出，同时带一点 ±Y 上下分量。
  - ⚠️ 之前做成了「向上运动」，被判定为错误。火花不是上飘的火星，是向两侧迸开的撞击碎片。
- **X 方向**：只有极微小发散（`sparkSideX ≈ 0.25`），不要前后飞。

### 触发条件
- 前进侧按 `(scale - 1)` 加强：`rate = sparkBaseRate + (scale-1) * 10 * sparkPerScale`。
- **对峙循环呼吸不加强**（只保留极弱底噪，或直接设 0）—— 呼吸是僵持，不是撞击。
- 额外 burst：真正在前进时每 `sparkBurstInterval` 秒 `Emit(sparkBurstCount)` 发一次爆发，撞击感靠 burst。

### 参数表

| 参数 | 建议默认 | 说明 |
|---|---|---|
| `sparkBaseRate` | 18 | 基础每秒发射数（旧版 6 太稀，看不到） |
| `sparkPerScale` | 18 | 倍率每 +0.1 增加的发射强度 |
| `sparkSideZ` | 2.2 | ±Z 两侧迸射速度（主方向） |
| `sparkUp` | 1.4 | ±Y 上下分量 |
| `sparkSideX` | 0.25 | X 微小发散 |
| `sparkLifetime` | 0.65 | 寿命（旧版 0.45 偏短） |
| `sparkSize` | 0.24 | 粒子尺寸（0.12 太小看不见） |
| `sparkBurstInterval` | 0.2 | burst 间隔 |
| `sparkBurstCount` | 6 | 每次 burst 数量 |
| 颜色 HDR | 1.6~2.5 | 过 1 才会被 Bloom 泛出 |

### 实现要点
- `startSpeed = 0`，方向**完全由 `velocityOverLifetime` 控制**（不要用 startSpeed + randomDirection，会四散飞走）。
- 发射口 shape：竖直细条 Box(0.05, 0.7, 0.25)，只覆盖中缝线一小段。
- 粒子模拟空间用 **World**，不随父物体拉伸。

## 2. ② 能量注入波（Inject Wave）

### 设计意图
判定线在后方持续为冲击波「供能」：一道能量波从后方射向冲击波，越远越强（显得优势大）。

### 关键约束（用户指定）
- **起点固定**：在判定线的世界坐标，**不随冲击波移动**。
  - ⚠️ 起点不能用墙的 `bounds` 推算 —— 墙是刚性平移，bounds 差值恒定，会导致「越远越强」完全失效。
  - 正确做法：`preview.baseRootWorldX + leftEdge / rightEdge`（需要 Preview 暴露这个只读属性）。
- **越远越强 = 显现式加强**：提高发射数 / 速度 / 亮度，**不做拉伸变形**（拉扯会变形得很厉害）。
- **必须是一道连贯的波，不是铺满画面的粒子雨**。
  - 这是之前最大的失败点：连续高发射率 + 长 lifetime → 整屏亮白。
  - 做法：低发射率 + 成束（严格直线飞）+ **每个粒子带 Trail**，靠 Trail 串出连贯感。

### 参数表

| 参数 | 建议默认 | 说明 |
|---|---|---|
| `injectRate` | 1.5 | 每秒发射数。**越低越像一道波**，高了就是粒子雨（曾 30 → 灾难） |
| `injectSpeed` | 3.0 | 飞行速度，快才拉得出 Trail |
| `injectSize` | 0.18 | 单粒子尺寸（偏大，像能量块） |
| `injectHalfWidthZ` | 0.5 | 发射口 Z 半宽，只在中缝附近，不铺满墙宽 |
| `injectSpreadY` | 0.5 | Y 方向散布 |
| `injectFarBoost` | 0.22 | 越远加强系数（保守，曾 0.35 造成过曝） |
| `randomDirectionAmount` | **0** | 严格直线朝中缝飞，才连得成波 |
| `trailLifetime` | 0.75 | Trail 占粒子寿命比例 —— **连贯感全靠它** |
| `trailWidth` | 0.85 | Trail 宽度 |
| `trailMinVertex` | 0.03 | 最小顶点距离 |

### 实现要点
- Shape 用 Circle 半径 0.18（成束），不要用 Box z=7（会散成雾）。
- Trail 参数每帧同步，Inspector 改了立刻生效，不用重建粒子系统。
- lifetime = `dist / speed`，保证粒子刚好飞到中缝就消失。
- 发射口 Z 固定为 0（中缝线）。

## 3. ③ 消散飘散（Dissolve + Drift）

### 设计意图
冲击波的边缘一直在轻微飘散（循环），前进时加强 —— 表现「能量在耗散」。

### 侵蚀顺序（用户指定，不可改）
从**身后（backX 侧）** 与 **两侧 z 边缘**开始，向中缝 / 中央推进。
- ⚠️ **头部（t→1）与拱顶必须保护**：之前没做保护，结果整片噪点全跑到头部去了，非常难看。

### 参数表

| 参数 | 建议默认 | 说明 |
|---|---|---|
| `dissolveIdle` | 0.04~0.12 | 循环（待机轻微） |
| `dissolveAdvance` | 0.14 | 前进时额外加强量 |
| `driftBaseRate` | 8 | 飘散粒子每秒发射数 |
| `driftBackPortion` | 0.45 | 只从墙的**身后段**生成（红=bounds.min.x 侧，蓝=max.x 侧） |
| `driftSpreadZ` | 0.7~0.8 | 朝 Z 两侧散开 |
| `driftRise` | 0.35 | 上飘 |
| `driftSize` | 0.09 | 粒子尺寸 |
| `driftLifetime` | 1.4 | 寿命 |

### Shader 保护区公式（已验证有效，实现时直接用）
```hlsl
float fromBack = 1.0 - t;
float fromSide = edge * (1.0 - t * 0.7);   // 头部两侧几乎不侵蚀
float fromTop  = vy * 0.08 * (1.0 - t);    // 顶部只在身后轻微侵蚀
float erode = saturate(fromBack * 0.85 + fromSide * 0.30 + fromTop * 0.10);

// 头部保护区：t 越大、vy 越高，越难被侵蚀
float protect = pow(t, 0.45) * (1.0 - edge * 0.25) * (1.0 - vy * 0.15);
erode = saturate(erode - protect * 1.6);

// 噪声幅度务必小（0.08），0.18 会让头部出现明显噪点
float n = frac(sin(dot(uv, float2(12.9898, 78.233))) * 43758.5453);
erode = saturate(erode + (n - 0.5) * 0.08);
```

### 实现要点
- Dissolve 需要 shader 新增 `_Dissolve` + `_ZHalf`（由 generator 同步 `zHalfRange`）。
- ⚠️ **顺序坑**：VFX 必须用 `LateUpdate`（排在 Preview.Update → `SyncMaterial` 之后），
  否则 `_Dissolve` 每帧被 `SyncMaterial` 覆盖回基础值，看起来完全没生效。

## 4. 已踩过的坑（实现前必读）

| # | 坑 | 现象 | 正确做法 |
|---|---|---|---|
| 1 | `velocityOverLifetime` 三轴混用模式 | Console 报错 `Particle Velocity curves must all be in the same mode` | 三轴统一用 `MinMaxCurve(min,max)`，min=max 即恒定值 |
| 2 | 注入发射率过高 + lifetime 过长 | 整屏亮白粒子雨、严重过曝 | 发射率降到 1~3，靠 Trail 出连贯感 |
| 3 | 消散无头部保护 + 噪声幅度大 | 头部一堆噪点 | 用上面的保护区公式，噪声 ≤ 0.08 |
| 4 | 火花 `randomDirectionAmount` 过大 | 粒子四散飞，什么都看不见 | 设 0，方向全交给 velocityOverLifetime |
| 5 | 注入起点用墙 bounds 推算 | 「越远越强」失效 | 用 `preview.baseRootWorldX + leftEdge/rightEdge` |
| 6 | VFX 用 Update 而非 LateUpdate | `_Dissolve` 每帧被 SyncMaterial 覆盖 | 必须 LateUpdate |
| 7 | 一次性上全部特效 | 无法归因，越改越乱 | 一次一个，逐个验收 |
| 8 | 改 shader 坐标空间（positionOS → 世界坐标） | **冲击波完全消失**（alpha=0） | **shader 坐标空间锁死 positionOS，永不再改** |

## 5. 实现顺序与验收标准

| 步 | 效果 | 验收标准 | 回退方式 |
|---|---|---|---|
| 4-1 | **碰撞火花** | 中缝线上能看到向两侧迸开的火花；前进时变密；僵持时几乎看不到 | `enableSpark = false` |

| 4-3 | **消散飘散** | 边缘/身后有轻微飘散，**头部保持完整无噪点**；前进时加强 | `enableDrift = false` + `dissolveIdle = 0` |
