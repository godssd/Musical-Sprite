## 2. 从示意图提炼的视觉目标

- 形体：使用实际 FBX 的有厚度墙体。中间墙面较直，两端在地面方向回弯；顶面、主面与转角要读得出来。
- 结构线：黄白／青白亮边跟随模型真实结构，宽窄略有手绘变化。结构亮边固定在形体上，不随表面流纹整体漂移。
- 色块：每侧优先用三到四个大色阶组织。红侧为深红、红橙、浅橙与淡黄亮边；蓝侧为深蓝、蓝色、青色与浅青亮边。颜色以用户示意图取样为起点。
- 整体性：主体色块连贯，细节集中在结构转折和后缘。通过色面关系与透光表现厚度，控制发光以保留色阶。
- 表面动态：能量从碰撞前沿沿墙面向各自半场后方流动，使用少量宽窄不同的大流纹，具有轻微形变。
- 尾缘：从主色面自然延伸出短而宽、长短不一的侵蚀边；与主体相连后局部断开。取消横跨场地的长条效果。
- 飘散：少量有明确轮廓的手绘短片，部分带一块内侧亮色，先沿模型两端弯曲轮廓运动，再略向己方后侧脱离。原碰撞火花与新增尾缘碎片保持各自用途。
- 后向光效：红色仅铺向红方半场、蓝色仅铺向蓝方半场，随主体由近到远淡出。制作副本关闭原有跨侧混合的全局染色，使用副本自己的局部光面。

静帧中的碎片位置不是固定发射点，最终须依据真实模型后缘、游戏镜头和音符遮挡情况确定。

## 3. 新资产制作

所有资源使用新的目录与文件名，避免覆盖当前资源。

| 新资产 | 内容 | 用途 |
|---|---|---|
| 结构遮罩 | 亮边、主面、暗侧面的区域控制；适配现有网格 | 保证体积与结构线稳定 |
| 流纹遮罩 | 两组可循环的大笔触，留足空白，轻微边缘不规则 | 形成从前向后的表面动态 |
| 尾缘侵蚀遮罩 | 大块缺口、短片与方向性断裂 | 控制后缘溶解与短尾形态 |
| 碎片图集 | 3～4 种短楔形／不规则薄片，主体与内亮面可分色 | 少量、有体积暗示的飘散 |
| 新 Shader 与红蓝材质 | 独立色阶、结构亮边、流纹、尾缘侵蚀参数 | 在副本内统一组织表现 |
| 新美术控制组件 | 读取现有墙体状态，驱动新增表现 | 跟随当前位移、缩放与闪亮反馈 |

贴图优先采用灰度／通道遮罩，以两套配色复用形状。结构与流纹先按 512～1024 分辨率制作，碎片图集按 256～512 制作；按实际镜头占屏大小决定最终规格。

结构定位先检查现有 FBX 的 UV、法线与坐标方向。优先通过独立遮罩和局部坐标适配；若必须修改原模型或 UV，需重新问询，不在本方案内默认执行。

## 4. 表现实现方法

### 4.1 主体与结构边

在原墙体网格上使用新材质。用结构遮罩与面向关系区分顶面、主面和暗侧面；亮边具有少量粗细变化，但保持连续结构。主体保有局部半透明，避免把墙做成实心石板。

第一轮只做静态色面，关闭新增流动和碎片，先在游戏实际视角判断是否能读出墙厚与两端回弯。

### 4.2 从头部向后的表面流动

用两层低频手绘流纹，以不同速度和相位沿表面从碰撞前沿流向后缘。大层决定主要色块运动，小层仅补少量亮纹；保留大面积稳定底色。

流纹在模型表面内变化，不拖动结构亮边，不改变模型轮廓。左右分别确认运动方向，避免镜像后出现同向滚动。初调可让一组大纹样约 1～2 秒掠过有效表面，最终以游戏镜头为准。

### 4.3 短尾缘与溶解

通过后缘位置遮罩与方向性侵蚀遮罩相乘，只影响墙后侧的局部区域。头部与主要结构边设保护区域。流纹进入侵蚀带后被拉成短片，再断裂淡出。

首轮优先由材质溶解完成尾缘；如需少量超出网格的短片，可新增依附模型后缘的短面片，不修改原 FBX。长短与间距不均匀，延伸距离以不抢主体、不遮挡音符为限。

### 4.4 少量手绘碎片

新增飘散组件从实际模型后缘采样发射，朝各自半场后方运动，略带外扩，逐渐减速、缩小并淡出。使用与尾缘相同的配色和轮廓语言，使脱离过程连贯。

初调以每侧同时可见约 2～4 片为起点。短片有大小变化，较大的轮廓承担主要阅读信息。所有数值属于新效果试调值，不代表已批准调整原火花。

## 5. 工程接入与兼容点

- 在 `VFXSandbox` 新增独立试验根节点，原组与试验组一次只显示一组。核对复制后的墙体、Preview 与 VFX 引用，防止跨组驱动。
- 新材质与贴图仅由试验组引用；共享 `WALL.fbx` 作为只读形体来源。
- 试验组停用旧 `ShockwaveTrail`；旧飘散通过其独立开关停用，保留原碰撞火花配置。
- 新控制组件只读取当前运动／缩放状态。现有 `ShockwaveMeshGenerator.SyncMaterial()` 与 Preview 会写入材质参数，新材质设计须避免参数被覆盖；优先使用独立美术参数和副本专用写入方式，同时兼容既有闪亮反馈。
- 当前飘散实验存在按旧拱形参数推算发射位置的逻辑。新增飘散使用实际 FBX 后缘定位，防止发射点脱离有厚度墙体。
- 原 P4 文档包含早期方案，其火花触发描述与当前代码有差异；本次以当前已运行行为和用户最新授权为准，不按旧文档重做火花。
- 通过副本显隐切换恢复原效果。后续若发现必须改共享脚本、旧资源或主场景，先列出受影响对象和原因，再问询。

## 6. 制作顺序与检查标准

各层已在试验副本中搭建。以下标准用于 Unity Game 视图逐项验收。

| 阶段 | 制作内容 | 通过标准 |
|---|---|---|
| 1 | 建立副本、静态配色、结构亮边和色面 | 与原模型一致；顶面／侧面清楚；缩小到实机大小仍能读懂；无整片过曝 |
| 2 | 表面流纹 | 明确从头部向后；结构线稳定；没有满屏碎噪与高频闪烁 |
| 3 | 短尾缘和局部溶解 | 头部完整；后缘有大块断裂变化；没有长条横跨场地 |
| 4 | 少量手绘碎片，与原火花组合观看 | 碎片和尾缘衔接；原火花仍可辨认；整体不变碎、不抢音符 |
| 5 | 制作场景内检查不同位置／缩放状态 | 两端回弯结构保留；流动方向一致；无穿插、UV 拉伸突变或排序闪烁 |

最终提交：试验组、新资产清单、参数说明、对比静帧，以及包含常驻流动／推进变化／尾缘消散的短录屏。当前阶段的验收在制作场景内进行；迁入主场景另行问询。
