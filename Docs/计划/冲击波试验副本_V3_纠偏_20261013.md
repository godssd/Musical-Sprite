# 冲击波试验副本 V3：对 V2 画面纠偏

用户截图表明 V2 比 V1 离目标更远：三角形扫片外伸过长，短尾迹呈大块楔形，盖过厚墙主体；表面仍像两块平直的色板。

本次只调整制作场景试验副本使用的 `SandboxShockwaveArt`：

- 移除端部的三角形拼片。每个端部改成一条 16 段的弯曲、收尖宽笔触，附一条更窄的内部色带。宽度、伸出距离和摆动幅度均收小。
- 移除三块大楔形尾迹，改为中央音轨间的三条短笔触；地面弱光长度缩短。
- 原 `WALL.fbx`、两方的独立墙体材质、预览运动逻辑及碰撞火花均不改。

脚本单独编译通过。Unity 窗口当前无法捕获，因此 V3 仍需要以制作场景的 Game 视图判断：尤其是曲线笔触是否贴着卷曲端部、短尾迹是否足够整体、厚墙是否保持画面主角。此记录不将 V3 标记为已完成视觉验收。
