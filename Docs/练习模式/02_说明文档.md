## 一、这个功能是做什么的

《Musical-Sprite》是一款 3D 锁视角对战音游。进入正式对战前，玩家需要一个**安全、可反复练习、可调参数**的环境来熟悉操作、谱面与角色。本功能是**「练习模式」**，包含两种玩法：

- **AI 对战（P0，优先做）**：你组一支队伍，AI 组一支队伍，双方**真实对战**，有判定、连击、胜负。适合练习整体对战节奏和阵容搭配。
- **单人练习（P1）**：只有你一个人真实出音符，对面是一个**占位机器人**（不打架，只按节奏给自己加分）。你可以随时暂停、调机器人参数、换歌、换队伍，曲子结束会自动循环。适合纯练手法、记谱。

为什么「练习模式」是整个游戏流程里第一个被做成完整功能的模块？见下一节。

---

## 二、为什么先做练习模式，且 AI 对战排在单人练习前面

我们给整个游戏排了优先级（详见需求文档 §0）：

1. **P0 练习 · AI 对战** —— 现有的战斗 demo 已经接近「AI 双方对战」，直接复用 BattleScene 的成本最低，所以把它放在最前面，先把主循环（进游戏 → 选人 → 选歌 → 打一局 → 结算）完整跑通。
2. **P1 练习 · 单人练习** —— 在 AI 对战主循环跑通后，把「对手」换成占位机器人，加练习专属规则（HP≥1、机器人 tick 加分、半透明预览、循环、暂停调参）。
3. **P2 剧情第一章** —— 在快速/排位/讨伐之前。
4. **P3 快速 / 排位 / 讨伐** —— 需要联网服务器，当前最遥远，主菜单只留置灰入口。
5. **P4 剧情后续章节** —— 最后做。

一句话：**先让「能进、能选、能打、能结算」这条主循环成立，再叠加练习专属玩法，最后才是联网和剧情。**

## 三、玩家的完整旅程

### 路线 A：AI 对战（P0）
1. 主界面 → 点「练习模式」→ 弹窗选「AI 对战」。
2. 选**乐队规模**（双人 / 三人 / 四人 / 五人）。
3. 进**角色选择界面**：从左侧仓库选角色填进右侧队伍槽位，可拖动换位、可切皮肤页签。主角小熊固定在中间主位。
4. 进 **AI 阵容选择**：AI 初始全员随机，规模和你完全一致；你可以把它改成指定角色，也可以保持随机。
5. 点 GO → 双方阵容确认 → 进**歌曲选择**（曲目 / 速度 / 难度）。
6. 开打：**真实双方对战**，正常判定胜负。
7. 结束弹窗：再来一局 / 更改乐队规模 / 更换角色 / 更换歌曲 / 退出练习。

### 路线 B：单人练习（P1）
1–5 同上（只是第 4 步没有 AI 阵容选择）。
6. 开打：只有你真实出音符、真实判定；对面是占位机器人，靠 tick 给自己加分；机器人侧场地里会**半透明提前显现你要打的音符**（仅预览）。双方 HP 都不低于 1。
7. 曲子结束**自动循环**；随时可暂停，暂停层有 6 项（继续 / 调机器人参数 / 回歌曲选择 / 回角色选择 / 回乐队规模选择 / 退出个人练习模式）。

## 四、核心概念解释（给新成员扫盲）

### 1. 乐队规模 与 音轨开放
乐队 = 1 个主角 + (规模-1) 个队伍角色。队伍角色占「音轨槽位」，不同规模开放的音轨不同（参考图底部 4 个站位 L→R = 音轨 0,1,2,3）：

| 规模 | 开放音轨 | 关闭音轨 |
|---|---|---|
| 双人（1+1） | 2 | 0,1,3 |
| 三人（1+2） | 2,1 | 0,3 |
| 四人（1+3） | 2,1,0 | 3 |
| 五人（1+4） | 0,1,2,3 全开 | — |

- **关闭的音轨位置完全不显示**（不渲染空框）。
- 主角固定在中央主位（非音轨位），不可换、不可拖动；当前只有小熊一个主角，所以实际换不了别人，但**更换交互功能保留**，以后加了新主角就能用。
- 队伍角色可以在**开放音轨之间拖动换位**。

### 2. 随机人物卡
仓库第一张卡是「随机人物」。把它放进队伍槽位后，**进战斗那一刻**会从你已拥有的角色里随机挑一个顶上（同一局内固定）。规则：
- 一支队伍里**不能出现重复角色**（随机和指定混用也不会撞）。
- 随机只在**自己这一侧**去重（你和对面可以同时上小熊，不冲突）。
- **每次开局都重新随机一次**（「再来一局」也会重新随机）。

### 3. 角色卡上的信息
- 左上小圆（彩色）= 角色标签（文档里的「角色类型」）。
- 左上原本的 "E" 我们没有这个数据，**直接隐藏**。
- 右上 = 角色名（原本写着的 "Yp:47" 那位置改成显示名字）。
- 中央 = 立绘。
- 底部两个数值 = **战斗力** 和 **HP**。
- 灰色带问号的槽 = 你还没解锁的角色。

### 4. 半透明音符（单人练习专属，最容易误解）
**不是镜像、不是装饰音符。** 它是**你自己的音符**，在机器人那一侧的场地上用半透明方式**提前显现**出来，让你提前看到自己要打什么（正常要越过粉杠才看得到）。但**代码层面这些半透明音符是隐身的**——不参与判定、不被输入系统响应，纯粹是给你看的预览。这样做是为了不干扰附魔等需要判定「还没显现的音符」的逻辑。

### 5. HP ≥ 1（单人练习）
练习模式下，你和机器人都不会被打死，血量最低停在 1。这样你可以无限循环练，不用担心 Game Over。

### 6. 机器人计分（单人练习）
机器人不出音符、没法靠命中得分，所以它**每隔一段时间（intervalSec）给自己加一点分（scorePerTick）**，模拟一个对手的存在感。这两个参数在暂停层里可以实时调。
