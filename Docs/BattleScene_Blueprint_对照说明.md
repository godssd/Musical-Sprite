## 1. 坐标 / 尺寸约定（先看这段，否则看表会困惑）

- **单位**：表里所有坐标、尺寸都是 Unity 世界单位（米）。
- **轴向**（游戏内约定）：
  - **X = 队伍轴**：红方 / 玩家在 **−X**（左），蓝方 / 敌方在 **+X**（右）。
  - **Y = 高度轴**：地面顶面在 Y≈0，角色 / 音符抬在 Y>0。
  - **Z = 音轨轴**：4 条音轨沿 Z 排布，位置 = **−2.25 / −0.75 / 0.75 / 2.25**（相邻间距 1.5）。
- **FBX 与 Unity 的坐标换算**：FBX 在 Blender 里是 Z 轴向上，导出时已做轴转换。结论——**FBX 里摆好的坐标就是游戏世界坐标，你不用自己换算**。若你改了某个物体的位置，告诉我它的 Blender 坐标，我用 `UnityX=BlenderX, UnityY=BlenderZ, UnityZ=−BlenderY` 帮你换算回 Unity。
- **尺寸写法**：`宽X × 高Y × 深Z`（盒体）；音符圆盘写 `直径 × 厚`；环写 `外径 ≈`。

## 5. 使用闭环（你接下来怎么做）

1. **打开** `BattleScene_Blueprint.fbx`（Blender 或拖进 Unity 看）。
2. **调布局**：改舞台宽度、音轨间距、角色站位/大小、粉杠高度等——造型、位置、大小都随便改。
3. **别改名**：物体名必须保持上表一致，否则我无法映射回 Unity。
4. **丢回给我**：导出（FBX / glTF 均可）发我。
5. **我回写**：按节点名 + 它的新坐标，反推你想要的布局，改到 `SampleScene.unity` / 对应代码（例如把角色 X 从 ±7.4 调到你要的值、舞台加宽到 X∈[−10,10]、音轨距改成 2.0）。
