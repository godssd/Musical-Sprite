# 能量槽规范

> 本文件记录能量槽（世界空间 mesh，浮角色脚下）的最终落地规则，从《Plan_音符与能量槽还原》萃取。
> 相关：资源命名见《命名规则》§4；数值向上取整见《角色Spine动画框架》§10；命名规则见《命名规则》。

---

## E1 位置方案（最终）

- 固定 `laneAnchors`（side / lane → 世界坐标），位置**钉死不跟随角色**。
- 玩家 `lane = -1` 吸附玩家标记（灰大方块）身下。
- 调位置：在 Inspector 的 `laneAnchors` 拖对应 `(side, lane)` 的 `Position`，运行时生效并保存。
- **【历史】** 脚底 BlobShadow 锚定方案因 Spine 接入后 cube 渲染器禁用 / pivot 不确定被弃用 → 最终走固定锚点。

## E2 状态机

- **aibo 4 态**：充盈（亮黄闪烁，`aiboFullA` 白↔黄）/ 一般（黄）/ CD 暗黄 / 空。
- **hero 3 态**：可用（银白↔暗灰闪烁，由技能 CD 驱动）/ CD（暗灰空槽 `releaseCol`）/ （双主动左右各一槽）。
- 玩家双主动 = 左右各一槽，各独立 3 态。

## E3 玩家槽由 CD 驱动

- 玩家 `energyCost = 0` → `maxEnergies` 全 0，但仍建条（`BuildForCharacter` 用 `activeSlots.Count` 作槽数）。
- 不依赖能量满判断，由技能 `busy`（CD 中）驱动：`!busy` → 可用闪烁；`busy` → CD 暗灰空槽。

## E4 CD 语义

- CD 只影响**释放**，充能不受影响（CD 中进度条仍在涨）。

## E5 样式（COTL）

- 胶囊形（`cornerFrac ≈ 0.95`）+ 粗黑描边（近黑 `0.04,0.04,0.04`）+ 近黑底 + 高饱和填充（Aura 黄 `1,0.85,0.20`）。
- 三层：BG 环 / 填充 / 底色（内部衬底）。
- **不引入新 Shader**（Doodle 抖动未加，需 URP 兼容验证）。

## E6 遮挡

- `Camera.main` 设 Custom 透明排序（`axis = 相机朝向`）。
- 三层 + Glow 同 `sortingOrder`，靠 `barRoot` 局部 Z 微偏移（`layerZTrack / Fill / BG / Glow`）分层，与 spine 同层按相机距离前后遮挡。

## E7 资源与加载

- 4 张灰度 Sprite（`EnergyBar_BG` / `BG_Dual` / `Track` / `Fill`，256×96，白 / 中灰，颜色由主题色 tint）在 `Assets/Art/UI/EnergyBar/`。
- 加载方式：**Inspector 拖引用**（弃 `Resources.Load`）。
- `EnergyBar_Fill_Dual` 用于玩家双槽：运行时 `Sprite.Create` 从正中切两半，各管一段。

## E8 开关与可调参数

- `showTrack`：黑底（Track）默认 false，只留槽环 + 条，可勾回。
- 全部参数 Inspector 可调：`barOutlinePixels` / `barFramePixels` / `barCornerRadiusFrac` / `barFillShrink` / `laneAnchors` / `showTrack` 等。
