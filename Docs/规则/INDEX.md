# 规则目录索引（Docs/规则/）

> ⛔ **规则使用铁律（最高优先级）**
> 1. 执行任务若牵扯到相关规则，**不得擅自违背，必须严格遵守**。
> 2. 若发现规则有问题 / 需要商榷，**必须先向用户汇报相关内容和情况**，不得自行其是或擅自改规则。
> 3. **只有用户明确强调"修改 / 调整规则"时**，才允许做出改规则或破例不遵守规则的操作。
> 4. 标注为"临时 / 待验证 / 待商榷"的条目，以文档内标签为准，同样适用上述铁律（改动前须汇报）。

## 使用建议

- 涉及具体规则内容时，请跳转到对应文档查阅；多文档交叉处已在各文档文末标注"关联 / 相关"。
- 本目录与 `../计划/` 分工：规则（不可违反的约定 + 用法规范）在此；开发计划 / 执行记录 / 交接 / 参考在 `../计划/`。
