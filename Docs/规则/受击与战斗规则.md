# 受击动画与战斗通用规则

> 本文档固化「受击表现」相关的一条**全角色通用**战斗规则。
> 不涉及任何角色特例——所有角色（玩家 / aibo）共用同一套判定。

---

## 1. 受击动画播放门槛（单次伤害 ≥ 阈值）

### 1.1 规则

- 战斗中对某侧造成伤害时，**仅当本次实际伤害 `damage >= hitAnimDamageThreshold`（默认 10，Inspector 可调）**，该侧**全队**才播放「受击动画」（含受击动画事件）。
- 若 `damage < hitAnimDamageThreshold`，该侧全队**只播「受击特效」钩子（PlayHitVfx）**，**不播受击动画**。
- 受击特效（VFX）当前为空实现占位，待美术接入；接入前不影响逻辑（低于门槛时也正常走钩子）。

### 1.2 为什么全队一起播

- 本游戏血量按 side **全队共享**，一次有效伤害同时作用于该侧整体；因此「≥ 阈值」时该侧所有角色方块一起播受击动画（含携带触发型被动技能的角色），视觉与逻辑一致。
- 「< 阈值」多是小额持续伤害（如 tick 伤害），只给轻量特效反馈更干净，避免满屏受击动画抖动。

### 1.3 事件链（实现位置，供查阅）

```
ScoreManager.OnSideDamaged(side, damage)         // 事件签名透传 damage
   ▼
CharacterBattleSystem.OnSideDamaged(side, damage)
   ├─ damage >= hitAnimDamageThreshold → 全队 marker.PlayHit()
   │       └─ 末尾抛 CharacterCubeMarker.OnHitAnimPlayed(marker)
   │          （被动技能唯一触发点，天然已满足门槛）
   └─ damage <  hitAnimDamageThreshold → 全队 marker.PlayHitVfx()
```

### 1.4 调参

- `CharacterBattleSystem.hitAnimDamageThreshold`（Inspector 可调，默认 10）。改这个值即可统一调整所有角色的受击动画门槛，无需逐个角色改。

---

## 2. 与其他规则的边界

- 受击动画是**纯表现层**规则，与「技能冷却 / 能量」无关；它只决定「什么时候播动画、什么时候只播特效」。
- 被动技能「真是条好狗（GoodDog）」以 `OnHitAnimPlayed` 为唯一触发点，因此**天然继承本门槛**——只有真正播了受击动画才会充能，小额伤害（< 阈值）不充能。其冷却由角色文档被动槽 `cooldown` 决定（见 `技能引用规则.md` §1.4 / §1.6），不在本规则范畴。
