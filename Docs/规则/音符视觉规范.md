# 音符视觉规范（⚠️ 临时 · 非绝对底层规则）

> **状态标签：临时（PROVISIONAL）**
> 本文件是从《Plan_音符与能量槽还原》萃取的**工作性观察与意图**，不是已锁定的绝对底层规则。
> 其中 **N4–N8 尚未完全实现或验证**，分别标记为【待验证】/【待商榷】/【未开始】。
> 若后续实现 / 验证后需调整这些条目，**必须先向用户汇报**，由用户决定是否改规则（见本目录 `INDEX.md` 的《规则使用铁律》）。
> 仅 **N1–N3** 是目前已落地、较稳定的约束。

---

## N1 同体换皮铁律（已落地 · 较稳定）

音符视觉替换只能在**同一个 `MeshRenderer` 体**上换材质 / 贴图，几何与跟随逻辑一行不动。

- **判定标准**：是否只换了材质 / 贴图，几何（尺寸 / 位置 / 粉杠显形数学）与运动逻辑是否未改。
- **来源**：SpriteRenderer 路线把整条渲染管线重建，导致过曝 / 尺寸爆长 / flip / 连线粗等全面失败，这是硬伤①的直接教训。

## N2 自定义 shader 禁令（已落地 · 较稳定）

自定义 `AdditiveSprite` / `CGPROGRAM` shader 在 URP17 下未加载 → 光晕退化过曝。

- 音符发光一律**不依赖**自定义 shader，改用 URP 内置 Additive 材质或 `RuntimeSpriteUtility.AdditiveGlow`（已确认可加载）。

## N3 尺寸铁律 A3（已落地 · 较稳定）

- 除跨轨外，所有音符视觉**不超当前轨**；跨轨只跨 2 轨。
- 视觉缩放只缩视觉尺寸（如 `tapVisualScaleMul`），**绝不动** `noteRadius` / 判定窗口（`goodWindow` / `perfectWindow`）。

---

## N4 显形 A4【待验证】

- **意图**：整枚音符越过粉杠（中线）后才出现。
- **【待验证】**：当前工程中**链接音符（Hold / 连线）在角度过大时，仍易出现"未越过粉杠就显示"的问题**，尚未修复，本条规则尚未完全成立。

## N5 命中 / Miss 反馈 A5 / A7【待商榷】

- **意图**：命中整体放大 ≈1.15 + 沿轨减速前进淡出；Miss 整体缩小先慢后快 + 减速前进；tint 驱动（白=命中 / 黑=Miss），不改其他音符类型颜色行为。
- **【待商榷】**：表现规则**后续仍可能调整**，未锁定。

## N6 跨轨换皮【待商榷 · 含义澄清】

- **含义**：跨轨点击音符（`isWideTap`）换皮使用 `Note_Wide.png`；缩放时 **X 与 Z 必须等比例乘同一个系数**（`tapVisualScaleMul` 同时作用于 X 和 Z），**不能只压 X**，否则贴图比例被破坏（爪印被拉伸变形）。
- **【待商榷】**：跨轨音符整体形态 / 比例仍是待打磨项。

## N7 立体感增量叠加【未开始】

- **意图**：轻立体化 = 受光(URP Lit) / 描边(COTL 粗黑) / 接触阴影 / 微厚度，逐层叠加、每步独立可验证，**不重建管线**。
- **【未开始】**：尚未实际尝试任何一层，仅作为方向记录。

## N8 普通点击资源与透明材质【未开始】

- **意图**：`Note_Tap.png`（透明背景，alpha=0 区透明）；材质用 URP Unlit + Transparent + `_BaseMap`；须强制 `_Surface=1` / `_Blend=1` / 关闭 AlphaClip / `renderQueue=Transparent` 才能正确透明。
- **【未开始】**：尚未正式接入验证。
