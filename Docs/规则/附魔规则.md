# 附魔规则（技能皮肤实装 · 统一依据）

> 本文件是附魔机制的**权威规则手册**：定义附魔名额如何按音符类型分解、附魔皮肤如何套用、逐节点 / 逐数字恢复行为。
> 配套资产生成见同目录 `RECOLOR_RULES.md`（每皮肤 31 张贴图的批量生成器与锚点）。
> 最后对齐：2026-09-20 与用户讨论确认（链接音符按"链接带归属下个音节"逐段、连点音符按"每个数字 1 次附魔"）。

---

## 0. 范围与视觉载体

- **视觉载体 = 换皮**：被附魔的音符**整体换成对应技能的主题皮肤贴图**（非发光染色叠加）。
- **特效（VFX）在换皮生效后再单独追加**（本轮不做）。
- 附魔皮肤集 = 每技能 31 张（清单与生成见 `RECOLOR_RULES.md` 第 1 节）。

---

## 1. 基本概念

- **附魔名额（charm quota）** = 技能 `charmedNoteCount` + 过热加成（普通/过热 ≤ 6，超级过热 ≤ 10）。
  由 `NoteSpawner.RequestCharm` 登记，`AssignPendingCharms` / `ReserveUpcomingCharms` 按时间就近消费。
- **附魔单位（charm unit）** = 名额的最小消费粒度，按音符类型不同（见第 3 节）。
- **完成（结算）**：普通 = 命中；链接节点 = 头节点命中 / 段 CLEAR；连点 = 每个数字命中。
  每完成 **1 个附魔单位** → `ActiveSkillRuntime.OnPerCharmSuccess` 触发 **1 次**效果（Bomb 投弹 / Heal 回血 / Dispel 驱散）。

## 2. 皮肤状态映射（以 `skill_X` 皮肤为例）

| 音符状态 | 普通点击 | 跨轨 / 链接节点 | 小型点击 | 连点 / 数字 | 链接带 |
|---|---|---|---|---|---|
| 附魔（未命中） | `Note_Tap_skill_X` | `Note_Wide_skill_X` | `Note_Tap_Small_skill_X` | `Note_Repeat{剩余数}_skill_X` | `Note_Slide_Link_skill_X` |
| 完成 / 命中后 | `Note_Tap_Select_skill_X` | `Note_Wide_Select_skill_X` | `Note_Tap_Small_Select_skill_X` | 切 Select 系 / 恢复原色 | `Note_Slide_Judgment_skill_X` |

- **未附魔**的音符显示**基础皮肤**（无 `_skill_X` 后缀的 `Note_Tap` / `Note_Wide` / `Note_Tap_Small` / `Note_Repeat{数}` / `Note_Slide_Link` 等）。
- `Select` 系 = 该音符"已命中 / 已完成"的视觉态（对应 `NoteMover.HitCoroutine` 里切 Select 贴图的行为）。

---

## 3. 各音符类型的附魔规则（核心）

### 3.1 普通 / 小型 / 跨轨点击

- **1 个音符 = 1 附魔单位**。
- 命中结算触发 1 次效果；整体换附魔皮肤（`Note_Tap_skill_X` → 命中后 `Note_Tap_Select_skill_X`）。

### 3.2 链接音符（Linked / Hold，K 节点）

- **K 节点 = K 附魔单位**。
- **起始节点 = 1 单位**（点击即得分，独立一部分）。
- 第 `i ≥ 1` 节点 + 其**入边链接带** = 1 部分。
  - **链接带皮肤归属（视觉细化，2026-09-20 P4）**：一条链接带只要其**任一端节点被附魔**，就显示附魔皮肤（头节点附魔→点亮其出边首段；尾节点附魔→点亮其入边末段；中间节点附魔→入边+出边两段都亮）。这样任何被附魔的音节点，与它接触的链接带都会亮起，**消除"头节点附魔了但首段链接带还是原色"的视觉缺口**。未附魔的、两端都未附魔的链接带保持原色。
  - 严格"链接带归属下个音节"判定等价于：下个节点附魔→入边带换皮肤；P4 进一步让头节点也点亮出边，避免孤儿段。
- 每个节点完成（头节点命中 / 段 CLEAR）各触发 **1 次**效果。
- 示例：**三链接音符 = 可附魔 3 次、可完成 3 次附魔**。

### 3.3 连点音符（N 连）

- **N 个数字 = N 附魔单位**（整条最多占 N 名额）。
- **附魔 K 次（允许部分附魔）**：**前 K 个连续数字**附魔，每个命中触发 1 次效果。
- 第 **K+1 个数字起恢复原色**（显示基础皮肤 / 未附魔外观）。
- 部分附魔**占 K 名额**（未附魔的数字不占名额）。
- 等效理解：连点音符 = 多个音符叠加成的音符，对技能而言每完成一次附魔命中即完成一次附魔。

## 6. 铁律

- 附魔单位计数必须与"完成次数"一一对应：每完成 1 单位 = 1 次效果。
- 连点音符"恢复原色"= 切回**基础皮肤**（未附魔外观），不是另一种附魔色。
- 链接带染色粒度 = **连续附魔区间整体点亮**（首/末被附魔节点之间的所有链接带整段染，含未拿到名额的中间节点所在段），不逐段孤立判定。
- 数值 / 计数向上取整为整数（沿用项目全局规则）。
