# 命名规则（Musical-Sprite）

> 本文件是项目内**所有命名约定的唯一事实源**。改动命名时，务必同步本文件、相应代码与资源。
> 相关规则：角色 Spine 动画命名见《角色Spine动画框架》；附魔皮肤命名见《附魔规则》；能量条资源命名见《能量槽规范》。

- 中文显示名仅用于 HUD / 文档；代码层一律用英文代码名。

## 3. Spine 动画全名

运行时完整动画名 = `animationPrefix` + `"_"` + 标准槽位后缀：

```
Aibo_2_Shit_02_Play_Normal
Player_01_Bear_12_Skill_Start
```

- `animationPrefix` 来自 `CharacterDataSO.animationPrefix`（即上面的代码层文件名，如 `Aibo_2_Shit`）。
- 标准槽位后缀（18 项，含两位零填充）由 `CharacterAnimator.SlotTable` 统一维护，**所有角色通用**。完整后缀表见《角色Spine动画框架》§3。

## 4. 美术资源目录与文件命名

| 类别 | 路径 / 命名 | 说明 |
|---|---|---|
| 角色 Spine 资源 | `Assets/Art/Characters/{英文名}/`（如 `Shit/`） | 每个角色一个目录，参考 `Assets/Art/Characters/Shit/` |
| 附魔换皮皮肤 | `Resources/EnchantSkins/{skillId}/{kind}_{skillId}.png` | 整张换皮，非染色叠加；详见《附魔规则》 |
| 能量槽 Sprite | `Assets/Art/UI/EnergyBar/EnergyBar_*.png` | 灰度图，颜色由 `EnergyTheme` 主题色 tint；详见《能量槽规范》 |
| 场景 / 蓝图节点 | 节点名 = 场景 GameObject 名 | `BattleScene_Blueprint.fbx` 内节点与场景对象一一对应 |

## 5. 废弃命名黑名单（一律作废）

以下早期命名**已全部作废**，新资源 / 代码 / 文档严禁使用：

- 角色：`Char_Xiong` / `Char_Dog` / `Char_DuDu` / `Char_BuMu` / `Char_Hei` / `Char_XiaoHei`
- 任何拼音缩写角色代号

统一改用 §1 的 `Player_*` / `Aibo_*` 体系。

## 6. 命名同步铁律

修改任一命名（角色代码名 / skillId / 动画前缀 / 资源文件名）时，**必须同步以下四处**，否则会出现引用断裂：

1. 本文件《命名规则》
2. `Assets/Data/Characters/Characters.xlsx`（飞书原表 1:1）
3. `Tools/gen_characters_xlsx.py`（xlsx 重新生成脚本）
4. `Assets/Editor/SkillLibraryGenerator.cs`（技能库自动生成器）
